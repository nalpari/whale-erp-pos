## 1. 목표

[매장정보] 탭에서 고객 앱(픽업오더 앱)에 보이는 점포 소개 · 점포 공지 · 편의시설 및 서비스를 매장이 직접 고친다.

- **이번 범위 밖**: 대표메뉴(1차에 없음, Q38), 태그 목록 관리(웨일ERP 공통코드, Q39), 앱 쪽 표시(앱 팀).

## 2. 권한 (Q09)

- 점포번호 계정 · 웨일ERP 계정 모두 보고 고칠 수 있다.

## 3. 화면 (p.15)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 안내 문구 | 「매장정보는 픽업오더 앱에 표시됩니다. 점포 소개와 점포 공지는 매장 화면에, 편의시설 및 서비스는 점포정보 화면에 표시됩니다.」 (Q38에서 고친 문구) |
| 2 | 점포 소개 | **필수**. 100자 · 최대 3줄, 줄바꿈 가능. 칸 아래 「50 / 100자」 |
| 3 | 점포 공지 | 200자 · 최대 5줄, 줄바꿈 가능. 칸은 5줄이 다 보이는 높이(∧/∨ 버튼 없음, Q39). 오른쪽 토글: 앱에 표시 / 표시 안 함. 칸 아래 「0 / 200자」 |
| 4 | 편의시설 및 서비스 | 서버가 주는 묶음 · 태그를 체크 상자로(1차 값: 결제수단 — 제로페이 · 애플페이 / 편의 — 주차 · 좌석보유 · 와이파이 · 화장실 / 동반 — 반려동물 · 유아의자 · 유아시설 / 운영 — 배달 · 연중무휴 · 남녀화장실구분). 오른쪽 토글: 앱에 표시 / 표시 안 함 |
| 5 | [저장] | 바뀐 내용을 저장하고 앱에 반영 |

- 글자 수는 보이는 글자 하나를 1자로 센다(띄어쓰기 · 이모지 · 줄바꿈 포함, Q40). T05의 글자 세기 함수를 같이 쓴다.
- 한도를 넘게 붙여 넣으면 넘는 부분은 잘라 넣고 칸 아래에 「100자까지 입력할 수 있습니다.」 / 「200자까지 입력할 수 있습니다.」. 줄 수가 넘으면 「3줄까지 입력할 수 있습니다.」 / 「5줄까지 입력할 수 있습니다.」 (Q40). 한글 조합 중에는 자르지 않는다(T05와 같음).
- 토글을 꺼도 칸은 그대로 고칠 수 있다(앱에만 안 보임).
- 터치로 다룰 수 있게 체크 상자 · 토글 · 버튼 44px 이상. 1024 × 768에서 세로 스크롤로 다 볼 수 있다.

## 4. 저장

- [저장]은 바뀐 것이 있고 점포 소개가 비어 있지 않을 때만 눌린다. 점포 소개가 공백뿐이면 칸 아래 「점포 소개를 입력해 주세요.」.
- 누르면 저장 중 표시(버튼 잠금), 성공하면 「저장되었습니다」 토스트, 실패하면 「저장하지 못했습니다. 다시 시도해 주세요.」 토스트(입력값은 그대로, Q42와 같은 문구).
- 화면을 열 때 서버에서 읽어 온다. 읽기 실패면 「매장정보를 불러오지 못했습니다. [다시 시도]」, 그동안 [저장]은 막는다.
- 저장하지 않고 다른 탭으로 갈 때는 확인창(11장 A). 빈 공지 · 태그 0개인데 표시를 켠 경우는 그대로 저장(11장 B).
- 모든 요청 10초 제한(T03과 같음).

## 5. 데이터 (가정, 백엔드 협의 전)

- 백엔드 요청 문서 7.2 #5: 매장정보 조회 · 저장, 태그 목록(묶음 · 태그 이름 · 코드)은 웨일ERP 공통코드에서. 서버도 같은 기준으로 글자 수를 센다.
- 모의 서버가 1차 태그 12개와 예시 소개 · 공지를 준다. 저장하면 모의 서버 값이 바뀌어 다시 열 때 보인다.

## 7. 로그

- 남길 것: 읽기 · 저장 실패(원인 요약), 저장 성공(「매장정보 저장」 한 줄).
- 남기지 않을 것: 소개 · 공지 본문(점포가 쓴 글이라 길고 개인정보가 섞일 수 있다).

## 8. 테스트 전략

- 순수 함수: 글자 수(이모지 · 줄바꿈), 3줄 · 5줄 제한, 붙여넣기 자르기, 소개 필수 검사, 바뀐 것 판단.
- 화면: 열 때 읽기 · 실패 · 다시 시도, 소개 비면 [저장] 막힘 + 안내, 한도 안내 4가지, 토글 · 태그, 저장 성공 토스트 · 실패 토스트(값 유지), 다시 열면 저장한 값, 11장 A · B.

## 9. 경계

- **항상**: 서버가 주는 태그 목록을 그대로 보인다(코드에 태그 이름을 박지 않는다, 모의 서버 제외).
- **먼저 묻기**: 새 라이브러리, 스펙에 없는 칸.
- **하지 않기**: 대표메뉴, 태그 추가 · 수정.

## 10. 완료 기준

1. 열면 서버 값이 보이고, 저장한 값이 다시 열었을 때 그대로 보인다 (테스트).
2. 점포 소개가 비어 있으면 저장되지 않는다 (테스트).
3. 100자 · 200자 · 3줄 · 5줄을 넘겨 넣을 수 없고 안내가 보인다 (테스트).
4. 표시 토글 · 태그가 저장되고 다시 열면 그대로다 (테스트).
5. 1024 × 768에서 터치로 다룰 수 있고, 한글 입력이 자연스럽다 (Linux 실제 창 + Windows).
6. ① lint · typecheck · format · test · build · Rust 검사 통과, ② · ③ 리뷰 완료.
