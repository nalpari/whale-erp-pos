## 1. 목표

환경설정 [AI챗봇 인기메뉴 설정] 탭에서 고객 앱 AI 챗봇의 [인기 메뉴]에 나올 메뉴를 최대 5개 고른다. 챗봇 자체는 고객 앱 기능이고, 이 프로그램은 보여 줄 메뉴 목록만 정한다.

- **이번 범위 밖**: 챗봇 화면 · 칩 표시(앱 팀), 순서 바꾸기(기획에 없음).

## 2. 권한 (Q10)

- 점포번호 계정: 보기만 한다. 화면 표시는 11장 A (Q56 답변 대기).

## 3. 화면 (p.20 그림 기준, Q48 ①)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 안내 문구 | 「AI챗봇 인기메뉴에 노출할 메뉴를 추가합니다. 최대 5개까지 설정할 수 있습니다.」 |
| 2 | [+ 인기상품 추가] | 추가 팝업(4장)을 연다. 5개가 차면 막힌다 |
| 3 | 목록 | 상품명, 카테고리, 금액, 상태 꼬리표, [삭제]. 추가한 순서대로(먼저 추가한 것이 위) |

- 상태 꼬리표: 등록 뒤 일시품절이 된 메뉴는 「일시품절」, 숨김이 된 메뉴는 「숨김」(목록에는 남고 챗봇에서는 빠진다, Q48 ③). 품절 상태는 T09와 같은 품절 데이터에서 읽는다.
- 목록 위에 「N / 5개」를 보인다(11장 B).
- **[삭제]**: 확인창 「인기메뉴에서 삭제하시겠습니까?」 [취소] [확인] → 바로 삭제. 실패하면 목록에 남기고 「저장하지 못했습니다. 다시 시도해 주세요.」 (Q48 ①).
- [저장] 버튼은 없다. 추가 · 삭제는 바로 저장된다 (Q48 ①, Q42와 같음).
- 비었으면 「설정한 인기메뉴가 없습니다.」. 불러오기 실패면 「인기메뉴를 불러오지 못했습니다. [다시 시도]」.
- [AI챗봇 인기메뉴 설정] 탭을 누를 때마다 다시 조회한다(T09와 같음, 웨일ERP에서 바꾼 것도 보이게).
- 요청 중에는 그 줄 · 추가 버튼을 잠그고, 메인 탭 · 환경설정 하위 탭 이동을 막는다(T08 · T09와 같음).
- 버튼 · 행 44px 이상.

## 4. 인기상품 추가 팝업 (p.21, Q48 ②~④)

- T09 품절상품 추가 팝업과 같다. 다른 점만:
  - **[옵션] 탭 없음** — 메뉴만 고른다.
  - **숨김 메뉴는 고를 수 없다**(회색, 체크 막힘, 꼬리표 「숨김」). **일시품절 메뉴는 고를 수 있다**(꼬리표 「일시품절」).
  - 이미 인기메뉴인 것은 체크 막힘 + 「등록됨」.
  - **5개 한도**: 남은 자리(5 − 지금 개수)만큼 고르면 나머지 체크가 막힌다. 「N개 선택됨 (최대 M개 더)」처럼 남은 수를 보인다.
  - [추가하기]: 바로 저장, 팝업 유지, 「N개를 인기메뉴에 추가했습니다.」, 추가한 것은 「등록됨」. 5개가 차면 팝업에 「최대 5개까지 설정할 수 있습니다.」를 보인다(팝업은 닫지 않음). 일부만 추가되면 「N개를 인기메뉴에 추가했습니다. M개는 추가하지 못했습니다.」, 0개면 「M개는 추가하지 못했습니다.」(이유가 한도 · 숨김 · 이미 등록 중 무엇이든 맞게, 11장 C).
  - 검색 · [전체] · 카테고리 탭 · 체크 유지 · [닫기] · 실패 처리는 T09와 같다.
- 상품 목록은 T09의 상품 목록 API를 그대로 쓴다.

## 10. 완료 기준

1. 5개를 넘겨 고를 수 없고, 5개면 [+ 인기상품 추가]가 막힌다 (테스트).
2. 추가 · 삭제가 바로 저장되고 다시 열었을 때 그대로 보인다 (테스트).
3. 숨김 메뉴는 고를 수 없고 일시품절 메뉴는 고를 수 있다. 팝업에 [옵션] 탭이 없다 (테스트).
4. 점포번호 계정은 바꿀 수 없다 (테스트).
5. T09 메뉴품절 기능이 그대로 동작한다 (기존 테스트 + 실제 창).
6. 1024 × 768에서 터치로 다룰 수 있다 (Linux 실제 창 + Windows).
7. ① lint · typecheck · format · test · build · Rust 검사 통과, ② · ③ 리뷰 완료.
