# 스펙: 환경설정 — 주문설정 (`settings-order`)

- **태스크**: T20 (Plane WHALEERPPO-53)
- **근거**: `AGENTS.md` 확정 사항 「주문 정책 변경」 ② · ③ · ④ (2026-11-25 대표님 결정). Q20 「15분 고정」과 정책 ACP-09 · ORD-05를 바꾼다.
- **선행**: T03 주문 수신(설정값 받기), T04 주문접수 화면(경고 시각), T10 위젯설정(같은 환경설정 화면). T19 도착 시각과 같이 하거나 뒤에 한다.
- **상태**: 승인 (2026-11-25, 사용자)

## 1. 목표

환경설정에 [주문설정] 탭을 두고, 점포의 **미접수 자동 취소 시간**과 **도착 최소 시간**을 매장이 정한다. 두 값은 점포 단위라 서버에 저장하고, 그 점포의 모든 PC와 고객 앱에 같이 적용된다.

- **이번 범위 밖**: 30초 반복 알림 간격, 주문받기 자동 OFF 조건(연속 2건 · 1분 무신호)은 그대로 고정값이다.

## 2. 권한

- 점포번호 계정 · 웨일ERP 계정 모두 보고 바꿀 수 있다 (2026-11-25 대표님 결정).

## 3. 화면

화면 제목: 「주문 처리 시간을 설정합니다.」

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 하위 탭 | 위젯설정 / 프린터설정 / **주문설정** (맨 뒤에 더함. AI챗봇 인기메뉴 설정은 1차 범위에서 숨김, 2026-11-26. 되살리면 프린터설정과 주문설정 사이에 둔다) |
| 2 | 자동 취소 시간 | 「접수하지 않은 주문을 자동으로 취소하는 시간」. 5 · 10 · 15 · 20 · 25 · 30분 중 하나, 기본 15분. 설명 줄: 「이 시간 동안 접수하지 않으면 주문이 취소되고 고객에게 자동 환불됩니다.」 |
| 3 | 도착 최소 시간 | 「고객이 고를 수 있는 가장 빠른 도착 시간」. 5 · 10 · 15 · 20 · 25 · 30분 중 하나, 기본 5분. 설명 줄: 「고객 앱에는 이 시간부터 5분 단위로 보입니다.」 |

- 고르는 칸은 터치로 다룰 수 있게 44px 이상. 1024 × 768에서 스크롤 없이 들어가게 한다.

## 4. 저장 · 반영

- 바꾸면 바로 서버에 저장하고 「저장되었습니다」 토스트 (위젯 · 프린터설정과 같은 방식).
- 저장이 실패하면 값을 이전으로 되돌리고 「처리하지 못했습니다. 잠시 뒤 다시 시도해 주세요.」 토스트.
  - 예외: **시간 초과(10초)**면 서버에는 저장됐을 수 있으니, 같은 토스트를 띄운 뒤 서버에서 다시 읽어 실제 값을 보인다. 다시 읽기도 실패하면 이전 값으로 되돌린다(13장 F).
- 화면을 열 때 서버에서 읽는다. 읽기 실패면 「설정을 불러오지 못했습니다. [다시 시도]」.
- 다른 PC에서 바꾼 값은 다음에 이 화면을 열 때와 주문 목록을 다시 불러올 때(T03 시작 · 재연결 · 새로고침) 반영한다.

## 5. 자동 취소 시간이 쓰이는 곳

- 서버가 이 시간으로 접수대기 주문을 자동 취소한다(매장 프로그램이 꺼져 있어도, Q53 그대로).
- 주문접수 화면 카드의 경고: 결제 뒤 **(자동 취소 시간 − 3분)**부터 빨간 글자 「3분 뒤 자동 취소」 (T04 2.3을 바꿈). 자동 취소 시간이 5분이면 2분부터.
- 바꾼 값은 **바꾼 뒤 들어온 주문부터** 적용한다. 주문마다 들어올 때의 값을 쓴다(13장 B). 서버가 주문마다 **자동 취소 예정 시각 `autoCancelAt`**을 담아 준다(13장 D). 경고는 `autoCancelAt − 3분`부터다.
- 고객 알림 문구, 「매장취소 + 누가: 자동」 표기, 연속 2건 자동 OFF는 그대로.

## 6. 도착 최소 시간이 쓰이는 곳

- 고객 앱이 도착 시각 선택지를 이 값부터 5분 단위로 보인다(앱 · 서버 담당).
- 매장 프로그램은 값을 저장 · 보여 주기만 한다. 주문의 도착 예정 시각은 서버가 준 값을 그대로 쓴다(T19, `SPEC-order-board.md` 12장).

## 8. 로그

- 남길 것: 설정 읽기 · 저장 실패(원인 요약만), 저장 성공(바뀐 항목 이름과 값).
- 남기지 않을 것: 점포코드 · 아이디.

## 9. 테스트 전략

- 화면: 두 칸의 선택지와 기본값, 바꾸면 저장 API를 부르고 토스트, 실패면 되돌림, 읽기 실패 안내.
- 경고 계산: 자동 취소 15분 → 12분부터, 5분 → 2분부터, 30분 → 27분부터 (가짜 시계).

## 10. 경계

- **항상**: 점포 단위로 서버에 저장한다(PC에 저장하지 않는다).
- **먼저 묻기**: 새 라이브러리, 스펙에 없는 설정 항목.
- **하지 않기**: 자동 취소 · 자동 OFF를 매장 프로그램이 직접 하기(서버가 한다).

## 11. 완료 기준

1. 두 계정 모두 두 값을 바꿀 수 있고, 다시 열어도 서버 값이 보인다 (테스트).
2. 저장 실패 때 값이 되돌아가고 안내가 뜬다 (테스트).
3. 카드 경고가 「설정값 − 3분」부터 뜬다 (테스트 + 실제 창, 개발용 모의 패널로 확인).
4. ① lint · typecheck · format · test · build · Rust 검사 통과, ② · ③ 리뷰 완료.
