- **태스크**: T09 (Plane WHALEERPPO-10, `[F-SOLDOT]`), 태스크 문서 `docs/tasks/T09-soldout.md` (기획자 답변 전에 쓴 것이라 이 스펙이 우선한다)
- **근거**: 화면정의서 v0.8 p.16 · p.17, 기획자 답변 Q09 · Q41 · Q42 · Q43 (`docs/tasks/planner-answers.md`), 추가 문의 Q58(답변 대기), 백엔드 요청 문서 7.2 #6 · 7.3 #17, spec-store `whalepos` F-SOLDOT · S-SOREGI
- **선행**: T01 프로그램 틀, T02 로그인
- **상태**: 승인 (2026-11-19, 사용자)

## 1. 목표

[메뉴품절] 탭에서 재료가 떨어진 메뉴 · 옵션을 바로 품절로 바꿔 고객이 주문하지 못하게 하고, 다시 팔 때 품절을 지운다. 재고 관리가 아니라 "앱에서 팔지 않게 표시"하는 기능이다.

- **이번 범위 밖**: 재고 수량, 품절 자동 해제(Q41: 자동으로 풀리지 않음), 앱 쪽 표시(앱 팀), 이미 결제된 주문 처리(Q43 ②: 매장이 [주문취소] + 「재료가 소진되었습니다」).

## 2. 권한

- 점포번호 계정 · 웨일ERP 계정 모두 보고 바꿀 수 있다 (Q09 표). 확인 문의 Q58이 답변 대기라, 다르게 오면 그때 고친다.

## 3. 메뉴품절 화면 (p.16)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 안내 문구 | 「품절 상품을 삭제하면 해당 상품이 앱에서 다시 판매 가능 상태로 변경됩니다.」 |
| 2 | 상태 탭 | 전체 / 일시품절 / 숨김, 탭마다 건수 |
| 3 | 품절 목록 | 상품명, 메뉴 / 옵션 구분, 카테고리, 금액, 표시방식(라디오: 일시품절 · 숨김), [삭제] |
| 4 | [+ 품절 상품 추가] | 추가 팝업(4장)을 연다 |

- 정렬: 최근에 추가한 것이 위.
- 표시방식 뜻: **일시품절** — 앱에 보이고 회색 + 「일시품절」, 고를 수 없음. **숨김** — 앱에 보이지 않음 (Q43 ①).
- **표시방식 라디오는 바꾸면 바로 저장**하고 「저장되었습니다」 토스트. 실패하면 라디오를 원래대로 되돌리고 「저장하지 못했습니다. 다시 시도해 주세요.」 (Q42).
- **[삭제]**: 확인창 「품절상품을 삭제하시겠습니까?」 + 다음 줄 「삭제하면 앱에서 바로 다시 판매됩니다.」, [취소] [확인]. [확인]이면 바로 삭제되어 목록에서 빠진다. 실패하면 목록에 남기고 같은 실패 토스트 (Q42).
- 품절은 자동으로 풀리지 않는다. 다음 날에도 직접 삭제할 때까지 남는다 (Q41 ①).
- 품절 목록은 웨일ERP와 같은 데이터다. 어느 쪽에서 바꿔도 같이 바뀐다 (Q41 ②, 갱신 시점은 11장 A).
- 목록이 비면 「품절 상품이 없습니다.」. 불러오기 실패면 「품절 목록을 불러오지 못했습니다. [다시 시도]」.
- 한 줄에서 요청 중에는 그 줄의 라디오 · [삭제]를 잠근다.
- 버튼 · 라디오 · 행은 44px 이상.

## 4. 품절상품 추가 팝업 (p.17 · Q42)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 상품명 검색 | 팝업 안에서 상품명으로 거른다(입력하면 바로) |
| 2 | 카테고리 탭 | 서버가 주는 카테고리 + 맨 끝 [옵션](옵션 항목만). 맨 앞 탭은 11장 B |
| 3 | 상품 목록 | 체크 상자, 상품명, 메뉴 / 옵션 구분, 카테고리, 금액. 이미 품절 등록된 항목(일시품절 · 숨김 모두)은 체크 상자를 막고 상품명 옆에 회색 바탕 「등록됨」 |
| 4 | 선택 정보 | 「N개 선택됨」을 바로바로 |
| 5 | [추가하기] | 고른 항목을 **일시품절로 바로 저장**. 팝업은 닫지 않는다. 「N개를 일시품절로 추가했습니다.」 토스트, 추가한 항목은 체크가 풀리고 「등록됨」으로 바뀌며 「N개 선택됨」은 0개. 뒤 화면 목록 맨 위에 바로 보인다. 고른 것이 0개면 눌리지 않는다 |
| 6 | [닫기] | 팝업만 닫는다 (바깥 누르기 · Esc로도 닫힘). 팝업은 [닫기]를 누를 때까지 유지 |

- 다른 카테고리로 옮겨 가도 고른 체크는 유지한다(카테고리를 넘나들며 한 번에 추가).
- [추가하기] 실패면 체크를 그대로 두고 「저장하지 못했습니다. 다시 시도해 주세요.」.
- 검색어 · 카테고리 · 체크는 팝업을 닫으면 지운다.
- 상품 목록을 못 불러오면 팝업 안에 「상품 목록을 불러오지 못했습니다. [다시 시도]」.

## 9. 경계

- **항상**: 바꾸면 바로 저장, 실패하면 화면을 원래대로.
- **먼저 묻기**: 새 라이브러리, 스펙에 없는 칸 · 버튼.
- **하지 않기**: 재고 수량, 자동 해제, 상품 정보 편집.

## 10. 완료 기준

1. 추가한 상품이 일시품절로 목록 맨 위에 나타나고, 팝업은 열린 채 그 상품이 「등록됨」이 된다 (테스트).
2. 이미 등록된 상품은 팝업에서 고를 수 없다 (테스트).
3. 표시방식 라디오는 바꾸면 바로 저장되고, 실패하면 되돌아간다 (테스트).
4. 삭제하면 확인창이 뜨고 [확인] 뒤 목록에서 빠진다 (테스트).
5. 탭 건수가 목록과 맞는다 (테스트).
6. 1024 × 768에서 터치로 다룰 수 있다 (Linux 실제 창 + Windows).
7. ① lint · typecheck · format · test · build · Rust 검사 통과, ② · ③ 리뷰 완료.
