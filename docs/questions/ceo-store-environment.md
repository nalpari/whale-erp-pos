# 대표님 확인 요청: 매장 POS 환경 및 운영 방침

> **목적**: 주문접수 프로그램(POS PC에 설치)의 개발 기술을 정하기 위해, 파일럿 매장 환경과 향후 가맹점 방침을 확인합니다.
> **배경**: Windows 버전과 프린터 연결 방식에 따라 사용할 수 있는 개발 기술이 크게 달라집니다. 2027년 2월 일정을 지키려면 이 답이 먼저 필요합니다.

---

## 0. 먼저 설명드릴 내용

### 0-1. Windows 7 이슈: 왜 Windows 버전을 묻는가

**한 줄 요약**: Windows 7은 이미 "단종된 운영체제"라서, 요즘 프로그램을 만드는 도구들이 더 이상 Windows 7을 지원하지 않습니다.

**상황**
- Microsoft는 **2020년 1월**에 Windows 7 지원을 공식 종료했습니다. 이후 보안 업데이트가 나오지 않습니다(기업용 유료 연장 지원도 2023년 1월에 끝남).
- 운영체제가 단종되면, 그 위에서 돌아가는 개발 도구들도 순서대로 지원을 끊습니다.

| 개발 부품 | 용도 | Windows 7 |
|---|---|---|
| Chrome / Edge 브라우저 | 웹 화면 표시 | 2023년 초(109 버전)가 마지막 |
| WebView2 | 프로그램 안에 웹 화면을 띄우는 부품 | 2023년 1월(109 버전)이 마지막 |
| **Tauri (우리 1순위 후보)** | 웹 화면 + 프로그램 본체 | **2026년 9월(2.12)에 Windows 7 공식 지원 중단 발표** |
| Rust (Tauri의 기반 언어) | 프로그램 본체 개발 | 2024년 5월(1.78)부터 Windows 10 이상만 지원 |
| Electron | 웹 기술로 PC 프로그램을 만드는 도구 | 2023년 2월 버전(23)부터 미지원 |
| 최신 .NET / Flutter | Windows 프로그램 개발 기반 | Windows 10 이상만 지원 |
| .NET Framework 4.8 | 구형 Windows 프로그램 개발 기반 | 설치는 가능 (Microsoft는 Win7을 지원 종료 OS로 표시) |

> 근거: `docs/research/store-order-receiver-tech-research.md` 2장 (Microsoft·Rust·Electron·Flutter 공식 문서)

**우리 프로젝트에 미치는 영향**
- Windows 7을 지원하려면 **몇 년 전 버전의 구형 도구**로 만들어야 합니다.
  - 개발 속도가 느려지고, 문제가 생겨도 해결 자료나 업데이트가 없습니다.
  - 구형 도구에 보안 문제가 발견돼도 고쳐지지 않습니다.
- Windows 7 PC는 최신 보안 인증서가 없어 **서버 접속(HTTPS)이 실패하는 경우**도 생길 수 있습니다. 주문을 인터넷으로 받는 프로그램이라 직접적인 위험입니다.
- 결과적으로 **"Windows 7도 지원"은 개발 기간 증가 + 운영 중 장애 위험 증가**를 뜻합니다.

**Windows 10도 확인이 필요한 이유**
- 일반 Windows 10(가정용·Pro)은 **2025년 10월에 지원이 끝났습니다**(유료/조건부 연장 지원 제외).
- 반면 POS 기기에 많이 들어가는 **Windows 10 IoT Enterprise LTSC 2021은 2032년 1월까지** 지원됩니다.
- 그래서 "Windows 10"이라도 **어떤 에디션인지**까지 확인하면 매장 PC를 얼마나 더 쓸 수 있는지 판단할 수 있습니다(Q1).

**그래서 드리는 제안**
- 파일럿 매장이 Windows 7이면, 그 PC 한 대를 Windows 10/11로 바꾸는 것이 개발 기간을 늘리는 것보다 저렴할 가능성이 큽니다.
- 가맹점 확장 시에는 **"Windows 10 이상"을 설치 조건**으로 안내하는 것을 권장합니다. 배달앱 주문접수 프로그램들도 비슷한 최소 사양을 둡니다.

### 0-2. 프린터 이슈: 왜 프린터 연결 방식을 묻는가

**한 줄 요약**: "PC에 프린터가 잡혀 있으면 아무 프로그램이나 출력할 수 있다"가 POS에서는 성립하지 않는 경우가 있습니다.

**프로그램이 프린터로 출력하는 방법은 두 가지입니다**

| | ① Windows 프린터(드라이버)로 출력 | ② 프린터 포트로 직접 출력 |
|---|---|---|
| 비유 | **사무실 공용 복사기**: 여러 사람이 출력해도 순서대로 줄 세워 처리 | **전화 한 회선**: 누가 통화 중이면 다른 사람은 통화 중 신호 |
| 방식 | 문서 인쇄처럼 Windows가 출력 순서를 관리 | 프로그램이 프린터 케이블(포트)을 직접 붙잡고 명령을 보냄 |
| 여러 프로그램이 함께 쓰기 | 대체로 **가능** | 한 프로그램이 붙잡고 있으면 **불가능** |
| POS에서의 사용 | 일부 POS | **한국 POS 프로그램에서 흔한 방식** (출력 속도·용지 커팅 제어 때문) |

**문제가 되는 상황**
- 기존 POS 프로그램이 ② 방식으로 프린터를 **계속 붙잡고 있으면**, 우리 프로그램은 같은 프린터로 출력할 수 없습니다.
- 특히 **시리얼(9핀) 케이블 연결**은 한 번에 한 프로그램만 쓸 수 있어 충돌 가능성이 가장 높습니다.
- 충돌이 나면 "주문을 접수했는데 주문서가 안 나옴" 또는 "POS 영수증이 안 나옴"이 발생합니다. 피크타임에 이런 일이 생기면 매장 운영에 직접 지장이 갑니다.

**연결 방식별 위험도**

| 연결 방식 | 함께 쓰기 | 위험도 |
|---|---|---|
| USB + Windows 드라이버 설치됨 | 대부분 가능 | 낮음 |
| 랜(네트워크) 케이블 | Windows 프린터로 등록돼 있으면 가능. POS가 프린터에 직접 연결하는 방식이면, 일부 모델(예: Epson TM-T20IV)은 출력 연결을 한 번에 하나만 받아 충돌 가능 | 낮음~중간 |
| 시리얼(9핀) | POS가 붙잡고 있으면 불가 | **높음** |

**해결 방법**

| 방법 | 비용 | 확실성 |
|---|---|---|
| **A. 주문서 전용 프린터 1대 추가** | 약 10~20만 원 | **가장 확실**: 기존 POS와 완전히 분리 |
| B. 기존 프린터를 드라이버 방식으로 함께 사용 | 없음 | 매장 POS 설정에 따라 가능 여부가 다름. 현장 확인 필요 |
| C. 기존 POS 업체에 연동 요청 | 업체 협의 필요 | 업체 협조와 일정에 좌우됨 |

**권장**: 파일럿은 **A(전용 프린터)** 로 위험을 없애고 시작합니다. 가맹점 확장 시 B가 가능한지 매장별로 판단합니다.

## A. 파일럿 매장 (대표님 매장)

### Q1. 매장 POS PC의 Windows 버전은 무엇인가요?

- **확인 방법**: POS PC에서 `Windows 키 + R` → `winver` 입력 → 엔터. 뜨는 창을 사진으로 찍어 주시면 됩니다. **에디션 이름(예: Windows 10 Pro, Windows 10 IoT Enterprise LTSC 2021)** 이 함께 보이도록 찍어 주세요.
- **왜 중요한가**: Windows 7은 2020년에 지원이 끝나서, 최신 개발 도구(웹 화면을 띄우는 부품 등) 상당수가 더 이상 Windows 7에서 동작하지 않습니다.
  - Windows 10/11 → 최신 기술로 빠르고 안정적으로 개발 가능
  - Windows 7 → 쓸 수 있는 기술이 제한되고, 개발 기간과 유지보수 부담이 늘어남

### Q2. (Q1이 Windows 7이라면) 파일럿 매장의 POS PC를 Windows 10/11 기기로 바꿀 수 있나요?

| 선택지 | 장점 | 단점 |
|---|---|---|
| **PC 교체 또는 업그레이드** | 최신 기술 사용, 개발 일정에 유리 | 기기 비용 발생, 기존 POS 프로그램 재설치 필요할 수 있음 |
| **Windows 7 그대로 지원** | 추가 비용 없음 | 구형 기술을 써야 해서 개발 기간 증가, 보안 업데이트 없는 환경 |

### Q3. 매장에서 쓰는 POS 프로그램(업체)은 무엇인가요?

- 예: 오케이포스, 포스뱅크, 토스플레이스, 배민포스, 유니온포스 등
- **왜 중요한가**: POS 프로그램이 프린터를 어떻게 쓰는지에 따라, 우리 프로그램이 같은 프린터를 함께 쓸 수 있는지가 갈립니다.
- **가능하면 POS 업체에 함께 물어봐 주세요**: "영수증 프린터를 ① Windows 프린터(드라이버)로 출력하나요, ② COM 포트를 직접 여나요, ③ 프린터 IP로 직접 연결하나요?"
  - ①이면 우리 프로그램도 같은 프린터를 함께 쓸 수 있는 구조입니다.
  - ②이면 POS가 포트를 열고 있는 동안 우리 프로그램은 출력할 수 없습니다(Windows 제약).
  - ③이면 서로 연결을 짧게 써야 해서 충돌 가능성이 있습니다.

### Q4. 영수증 프린터의 모델명과 연결 방식은 무엇인가요?

- **확인 방법**: 프린터 본체 뒷면/옆면의 모델명 스티커 사진, 그리고 PC와 연결된 케이블 사진
  - USB 케이블 / 랜(인터넷) 케이블 / 넓적한 9핀 커넥터(시리얼) 중 어느 것인지
- **왜 중요한가**: 특히 **시리얼(9핀) 연결**이면 기존 POS 프로그램이 프린터를 독점해서, 다른 프로그램이 출력하지 못하는 경우가 많습니다.

### Q5. 주문서 출력용 프린터를 한 대 따로 두는 것이 가능한가요?

- **비용**: 영수증 프린터 기준 대략 10~20만 원대
- **장점**: 기존 POS와 충돌할 위험이 사라지고, 주문서와 영수증이 섞이지 않음
- **고려사항**: 카운터에 놓을 공간, 전원/케이블 위치

### Q6. 매장 인터넷 환경은 어떤가요?

- 유선 인터넷인지, 와이파이인지
- 최근 인터넷이 끊긴 적이 자주 있었는지
- **왜 중요한가**: 주문은 인터넷으로 실시간 수신됩니다. 끊김이 잦다면 재연결·누락 방지 설계를 더 강하게 해야 합니다.

## B. 향후 가맹점 확장 방침

### Q7. 가맹점으로 확장할 때, Windows 7 매장도 지원해야 하나요?

| 선택지 | 의미 |
|---|---|
| **Windows 10 이상만 지원** | 가맹점에 "Windows 10 이상 PC"를 설치 조건으로 안내 (권장) |
| **Windows 7도 지원** | 모든 가맹점에서 바로 설치 가능하지만, 개발·유지보수 비용 증가 |
| **나중에 결정** | 파일럿은 매장 환경 기준으로 만들고, 확장 시점에 다시 판단 |

### Q8. 가맹점에 프린터 추가 구매나 PC 교체를 요구할 수 있나요?

- 본사가 장비를 지원하는지, 점주 부담인지
- **왜 중요한가**: "기존 장비를 그대로 써야 한다"가 조건이면 다양한 POS·프린터 조합을 모두 맞춰야 해서 개발 범위가 크게 늘어납니다.

### Q10. 파일럿이 "성공했다"고 판단하는 기준은 무엇인가요?

- 제안: **"대표님 매장에서 실제 앱 주문을 피크타임 포함 N주간 운영하는 동안, 주문 누락 0건, 주문서 출력 실패 0건"**
