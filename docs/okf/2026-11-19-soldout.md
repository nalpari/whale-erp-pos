# 목표
[메뉴품절] 탭에서 메뉴 · 옵션을 바로 품절로 바꾸고, 다시 팔 때 품절을 지운다. 완료 기준은 스펙 10장 1~7[^spec].

# 작업 내용
- [메뉴품절] 탭이 자리표시 대신 실제 화면이 됐다. 두 계정 모두 바꿀 수 있다(Q09, 확인 문의 Q58은 답변 대기)
- 안내 문구, 탭(전체 · 일시품절 · 숨김 + 건수), 목록(상품명 · 메뉴/옵션 · 카테고리 · 금액 · 표시방식 라디오 · [삭제]), 최근 추가가 위, 페이지 없이 스크롤
- 표시방식 라디오는 바꾸면 바로 저장 + 「저장되었습니다」, 실패면 되돌림 + 「저장하지 못했습니다. 다시 시도해 주세요.」. 요청 중 그 줄 잠금
- [삭제]: 확인창 「품절상품을 삭제하시겠습니까?」 + 「삭제하면 앱에서 바로 다시 판매됩니다.」 → [확인] 뒤 바로 삭제
- 추가 팝업: 검색, [전체] · 카테고리 · [옵션] 탭, 등록된 항목은 회색 「등록됨」 + 체크 막힘, 「N개 선택됨」, 카테고리를 넘나들어도 체크 유지, [추가하기]로 바로 일시품절 저장 · 팝업 유지 · 추가한 항목은 「등록됨」 · 뒤 목록 맨 위. 결과 문구는 모두 / 일부 / 0개 세 가지
- (머지 뒤 추가) 목록 상품명 검색: 입력하면 바로 거르고(팝업과 같은 함수) 탭 건수도 검색 기준, 결과 없으면 「검색된 품절 상품이 없습니다.」, 검색어는 재조회 · 탭 이동 뒤에도 유지(로그아웃하면 지움), × 지우기. 검색어가 있을 때 1개 이상 추가되면 검색어를 지워 추가한 항목이 맨 위에 보임
- (실제 창 확인 뒤 추가) 검색 줄을 한 줄로: [상품명 검색 칸(×)] [+ 품절 상품 추가], 그 아래 안내 문구 · 상태 탭. Enter는 입력칸 초점을 빼 화상 키보드를 닫는다([검색] 버튼은 넣었다가 사용자 요청으로 뺌)
- [메뉴품절] 탭을 누를 때마다 자동으로 다시 조회(웨일ERP에서 바꾼 품절도 보임), 저장 · 삭제 · 추가 요청 중에는 메인 탭 이동을 막음
