# 목표
기획자 답변(Q02~Q08 · Q51)에 맞춰 프로그램 틀을 고친다. 완료 기준은 스펙 9장 1~7[^spec].

# 작업 내용
- 더보기 메뉴를 아이콘 칸 6개로 바꿨다: 다시시작 · 로그아웃(로그인 후) · 프로그램 종료(빨간 아이콘) · 창 최소화 · 창 늘리기/줄이기(상태에 따라 하나만) · 로그 확인. 「시스템종료」라는 이름과 문구를 「프로그램 종료」로 바꿨다. 새로고침은 넣지 않았다(T03).
- [다시시작]: 확인창을 띄우고, 주문 중단을 요청한 뒤(실패해도 진행) 프로그램을 다시 켠다. 자동 로그인 토큰은 지우지 않는다. 다시 켜기에 실패하면 확인창을 닫고 토글을 OFF로 맞춘다.
- 주문받기 OFF · 다시시작 · 로그아웃 · 프로그램 종료 확인창에 "처리할 주문 N건" 경고 줄을 넣었다. 건수는 `pending-orders.ts`의 함수 하나가 돌려주며 T03 전까지는 0이라 줄이 보이지 않는다.
- 토글 요청이 실패하면 공용 Toast에 "처리하지 못했습니다. 잠시 후 다시 시도해 주세요."를 띄운다.
- 창 크기
  - 최소 크기는 1024 × 700이다.
  - 처음 실행하면 화면 전체로 연다.
  - 마지막 크기 · 위치 · 최대화 여부를 PC에 저장했다가 되살린다. 최소보다 작은 값이나 모니터 밖 값은 버린다.
  - [창 줄이기]는 1280 × 800으로 줄인다. 작업 영역이 이보다 작으면 작업 영역 크기로 줄이되, 1024 × 700보다 작게는 줄이지 않는다.
  - Alt + F4나 작업표시줄의 [창 닫기]를 누르면 [프로그램 종료] 확인창이 뜬다.

# 검증
- 지휘 세션이 직접 다시 돌린 명령: `pnpm lint` → `pnpm typecheck` → `pnpm format:check` → `pnpm test` → `pnpm build` → `cargo fmt --check` · `cargo clippy -- -D warnings` · `cargo test`
- 결과: 모두 통과했다. 화면 테스트는 22파일 248개(이전 203개), Rust 테스트는 34개.
- ② 리뷰: 지적 10건(중요 3 · 사소 7) 중 7건을 고치고 3건을 보류했다.
  - 고친 것: 다시시작 실패 때 토글이 OFF로 맞지 않던 문제, 물리 · 논리 픽셀을 섞어 가짜로 통과하던 테스트, 위치를 먼저 정하고 크기를 정하도록 순서 변경, 저장한 모니터의 배율 사용, 작은 화면에서 가운데 배치 등
  - 보류한 것: 켤 때 1280 × 800이 잠깐 보이는 현상(기능 문제 아님), 크기를 바꿀 때마다 최대화 여부를 묻는 호출, 주문 중단 요청 시간 제한(T03 실제 API 때)
- ③ 리뷰(코드 · 테스트 · 숨은 실패 · 타입 설계 · 주석): 지적 약 35건 중 약 20건을 고쳤다.
  - 주요 수정: `restart_app` 실패 때 프로그램이 그냥 꺼지던 문제, 되살리기에 실패해도 저장을 계속하고 화면 전체로 열기, 리스너 누수, 저장 실패 로그, 모니터 판정을 x · y 둘 다로, 엉뚱한 이유로 통과하던 테스트, 사실과 다른 주석 4건
- Windows 수동 확인 (사용자에게 요청)
  1. 처음 설치해 켜면 화면 전체로 열린다 (켜질 때 1280 × 800이 잠깐 보이는 것은 알려진 현상)
  2. 창을 줄이고 옮긴 뒤 껐다 켜면 같은 크기 · 위치로 열린다. 최대화 상태로 끄면 최대화로 열리고, 헤더를 두 번 누르면 마지막 보통 크기로 돌아온다
  3. 창 테두리를 끌어도 1024 × 700보다 작아지지 않는다
  4. 더보기 메뉴가 아이콘 칸으로 나온다. 프로그램 종료만 빨갛다. 늘리기/줄이기는 하나만 보인다. 새로고침은 없다
  5. 터치로 메뉴 칸과 확인창 버튼을 누르기 편하다
  6. [다시시작]을 누르면 확인창 뒤에 프로그램이 껐다 켜진다. 자동 로그인을 켜 뒀다면 자동으로 로그인되고, 주문받기는 OFF다 (설치 파일에서 실제로 새로 켜지는지 확인. Linux에서는 실행 확인을 하지 않았다)
  7. Alt + F4나 작업표시줄 [창 닫기]를 누르면 바로 꺼지지 않고 [프로그램 종료] 확인창이 뜬다
  8. 헤더 빈 곳을 끌면 창이 옮겨지고, 두 번 누르면 늘리기/줄이기가 된다
  9. 모니터가 2대인 PC: 보조 모니터에서 끄고 다시 켜면 그 모니터에 열린다. 보조 모니터를 뺀 뒤 켜면 주 모니터에 화면 전체로 열린다

# 결정 사항
- 처리할 주문 경고는 기능만 만들고 건수는 T03 전까지 0, 창 크기 · 위치 기억은 라이브러리 없이, 연결 끊김 띠와 새로고침은 T03으로 (2026-11-18 사용자)[^spec]
- 지원하는 가장 작은 화면은 1024 × 700이다. 이보다 작은 화면은 지원하지 않으므로 그런 화면을 위한 처리는 만들지 않는다 (2026-11-18 사용자)[^spec]
