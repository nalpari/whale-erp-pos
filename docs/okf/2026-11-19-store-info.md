# 목표
[매장정보] 탭에서 고객 앱에 보이는 점포 소개 · 공지 · 편의시설을 매장이 직접 고친다. 완료 기준은 스펙 10장 1~6[^spec].

# 작업 내용
- [매장정보] 탭이 자리표시 대신 실제 화면이 됐다. 두 계정 모두 고칠 수 있다(Q09)
- 안내 문구는 Q38에서 고친 문구
- 점포 소개(필수 · 100자 · 3줄), 점포 공지(200자 · 5줄 · 5줄 높이 칸, ∧/∨ 없음 · 앱 표시 토글), 편의시설 및 서비스(서버가 주는 묶음 · 태그 체크 · 앱 표시 토글), 글자 수 표시
- 글자 수는 보이는 글자 하나 = 1자(줄바꿈 · 이모지 포함). 한도 · 줄 수를 넘기면 **새로 넣은 부분만** 잘라 넣고 안내 4가지(「100자까지 …」 「200자까지 …」 「3줄까지 …」 「5줄까지 …」). 한글 조합 중에는 자르지 않는다
- [저장]은 바뀐 것이 있고 소개가 비지 않을 때만. 성공 「저장되었습니다」, 실패 「저장하지 못했습니다. 다시 시도해 주세요.」(값 유지). 읽기 실패면 [다시 시도] + 저장 막기
- 저장하지 않고 다른 메인 탭을 누르면 확인창 「저장하지 않은 내용이 있습니다.」 [취소] [나가기]. 저장 중에는 탭 이동을 막는다. 바탕화면 위젯이 [주문접수]로 보낼 때는 확인창 없이 이동하고 변경은 버린다
- 모의 서버가 1차 태그 12개와 예시 소개 · 공지를 준다
