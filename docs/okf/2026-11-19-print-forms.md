# 목표
[주문접수]를 누르면 주문서를 자동으로 뽑고, 요약 팝업 · 주문내역 상세에서 주문서 · 영수증을 다시 뽑으며, 출력에 실패해도 접수는 그대로 두고 알린다. 완료 기준은 스펙 10장 1~7[^spec].

# 작업 내용
- 주문서 자동 출력: 이 PC에서 접수가 서버에서 성공하면(본 창 · 위젯 · 요약 팝업) 「주문서」 체크된 슬롯마다 한 장. 같은 주문은 한 번만, 다른 PC 접수는 뽑지 않음
- 주문서 양식: 제목, 픽업번호 크게, 주문번호 · 주문일시 · 주문자 · 픽업예정, 요청사항(있을 때만 굵게), 메뉴 × 수량 + 옵션 한 줄씩 「ㄴ」, 메뉴 사이 구분선. 58 / 80mm 용지 폭에 맞춰 줄바꿈하고 길면 다음 장으로
- [주문서 인쇄](요약 팝업 · 주문내역 상세): 제조중 · 제조완료 · 픽업완료에서 켜짐. 이미 출력된 주문은 맨 위 「[재출력] HH:mm」, 「미출력」 주문은 실패한 슬롯에만 표시 없이
- [영수증 인쇄]: 미리보기 팝업 → 「영수증」 체크된 앞선 슬롯 한 대. 카드 · 간편결제 · 전액 할인(「결제 금액 0원」) · 취소 영수증(모든 금액 마이너스) 양식. 영수증 슬롯이 없으면 버튼이 막힘
- 출력 실패: 접수는 그대로, 경고음 한 번, 화면 아래 빨간 띠 「주문서를 출력하지 못했습니다. (슬롯 · 프린터 · 이유) [다시 인쇄] [×]」, 주문 카드 · 위젯 카드에 「미출력」. [다시 인쇄]는 실패 슬롯만. 인쇄 대기열이 30초 안에 끝나지 않으면 「출력 결과를 확인할 수 없습니다.」 띠. 실패 뒤 취소된 주문은 띠 · 「미출력」을 자동으로 지움
- 시험 인쇄도 같은 출력 명령과 슬롯 용지 폭을 쓴다
- 개발 모드에서는 실제 출력 대신 왼쪽 아래 [출력 미리보기] 패널에 종이 모양으로 그린다(운영 빌드에는 없음)
- 프로그램 로고 교체(사용자 요청, 별도 커밋): 앱 아이콘(흰 둥근 사각형 + 고래), 파비콘, 헤더 왼쪽 「P」 칸을 고래 로고로
