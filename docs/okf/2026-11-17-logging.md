# 목표

매장 PC에서 문제가 생겼을 때 원인을 찾을 수 있게, 화면 · Rust의 오류 · 경고 · 주요 사건을 PC 파일에 남기고, 점원도 앱 안에서 최근 로그를 보거나 로그 폴더를 열 수 있게 한다.[^spec]

# 작업 내용

- 앱이 오류 · 경고 · 주요 사건을 PC 파일에 남긴다. Windows는 `C:\Users\<사용자>\AppData\Local\com.whale.pickuporder.dev\logs\app.log`, Linux는 `~/.local/share/com.whale.pickuporder.dev/logs/app.log`. 릴리스 빌드에서도 남는다(T11 ③ 보류 해소).[^spec]
- 남기는 것: 화면의 `console.warn` · `console.error`, Rust 오류, 잡히지 않은 화면 오류(`error` · `unhandledrejection`)와 Rust panic, 주요 사건(앱 시작 · 종료, 로그인 성공 · 실패 종류, 로그아웃, 자동 로그인 결과, 주문받기 ON/OFF 결과, 시험 인쇄 결과, 설정 읽기 · 저장 실패).[^spec]
- 개인정보를 남기지 않는다: 계정 종류와 사유 종류만 남기고, 휴대폰 번호 · 점포 고유번호 · 마스터 아이디 · 토큰 · 요청 본문은 남기지 않는다. 오류는 이름과 문구만, Error가 아닌 객체는 종류만 남긴다.[^spec]
- 시각은 한국 시간(PC 로컬)이다. 파일은 5MB가 넘으면 `app_<날짜_시각>.log`로 보관되고, 보관 파일은 5개까지 남는다(지금 파일 포함 최대 6개, 약 30MB).
- 더보기(⋮) 메뉴에 **[로그 확인]**을 추가했다(화면정의서 밖, 개발자 추가 기능). 로그인 전 · 점포번호 · 마스터 계정 모두 쓸 수 있고, 로그 위치, [로그 폴더 열기](탐색기), [새로고침], 최근 200줄, [닫기]가 있다. 로그인 화면에서 열었다 닫아도 입력이 남는다.

- 접근: Tauri 공식 로그 플러그인에 파일 대상만 두고(info 이상, 5MB, KeepSome(5), UseLocal, 파일 이름 `app`), 화면은 `console` 브리지와 정해진 문장만 만드는 로그 함수(`src/shared/log/`)로 보낸다. 문장 함수는 계정 · 사유 종류만 받아 개인정보가 들어갈 자리를 없앴다. 로그 화면의 파일 읽기는 끝에서부터 읽고, 폴더 열기는 운영체제 명령(explorer · xdg-open · open)으로 새 라이브러리 없이 했다.
