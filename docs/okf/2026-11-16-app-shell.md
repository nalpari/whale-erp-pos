# 목표

모든 화면이 올라갈 바탕을 만든다. 점원이 로그인하면 탭이 열리고, 헤더에서 주문받기를 켜고 끄며, 더보기 메뉴로 창을 다루고 로그아웃 · 종료할 수 있다.[^spec]

완료 기준 (스펙 9장):

1. 로그인 전/후에 헤더와 탭이 p.5 상태 ①②③대로 바뀐다
2. 로그인 직후 토글 OFF, ON은 확인 없이, OFF는 팝업 뒤. 요청 중 잠금, 실패 시 원상태
3. 토글 OFF · 로그아웃 · 시스템종료 팝업 문구가 기획서와 같다
4. 탭 5개와 환경설정 하위 탭 3개를 오갈 수 있다
5. 로그아웃하면 "주문 중단" 요청 뒤 로그인 화면으로 돌아간다
6. 창 최소화 · 줄이기 · 늘리기 · 종료, 헤더 끌기가 Tauri 창에서 동작한다 (Windows 확인)
7. ① 통과, ② · ③ 리뷰 완료

# 작업 내용

- 로그인 전/후로 바뀌는 헤더 · 탭 5개 · 환경설정 하위 탭 3개와 빈 콘텐츠 화면. 로그인은 개발 모드에서만 보이는 모의 로그인 버튼으로 바꿔 본다.
- 제목 표시줄 없는 1280×800 창. 헤더를 끌어 창을 옮기고, 더보기 메뉴로 최소화 · 줄이기 · 늘리기 · 로그아웃 · 시스템종료를 한다.
- 주문받기 토글: 로그인 직후 OFF, ON은 바로, OFF는 확인 팝업 뒤. 서버(모의) 성공 뒤에만 바뀌고 요청 중에는 잠기며, 실패하면 원상태와 안내 문구.
- 로그아웃 · 시스템종료: 확인 팝업 → 진행 중인 토글 요청이 끝난 뒤 "주문 중단" 요청(실패해도 진행) → 로그인 화면 또는 종료.
- Alt+F4 · 작업표시줄 "창 닫기"를 가로채 시스템종료 팝업을 띄운다.

## Windows 확인 체크리스트 (사용자 확인 대기)

`pnpm tauri dev` 또는 설치 파일로 확인한다.

1. 제목 표시줄 없이 1280×800 창이 화면 가운데에 뜬다. 창 · 작업표시줄 이름이 "픽업오더 주문접수"
2. 헤더 빈 곳(로고 · 점포명 포함)을 끌면 창이 옮겨진다
3. 토글 · ⋮ 버튼 · 메뉴 항목 · 메뉴 버튼 사이 여백을 누르거나 끌어도 창이 움직이지 않는다
4. 헤더 빈 곳을 두 번 누르면 최대화 ↔ 원래 크기
5. ⋮ → 창 최소화: 작업표시줄로 내려가고, 작업표시줄을 누르면 돌아온다
6. ⋮ → 창 늘리기: 화면 전체로 커진다(작업표시줄은 가리지 않아야 함)
7. 늘린 상태에서 ⋮ → 창 줄이기: 1280×800으로 줄고 화면 정가운데로 간다
8. 메뉴를 연 채 헤더 빈 곳이나 콘텐츠를 누르면 메뉴가 닫힌다
9. Alt+F4: 창이 닫히지 않고 "시스템을 종료하겠습니까?" 팝업. [취소]면 그대로, [시스템 종료]면 프로그램이 끝나고 작업 관리자에 프로세스가 남지 않는다
10. 작업표시줄 아이콘 우클릭 → "창 닫기": 9와 같다
11. 로그인 후 토글 ON → ⋮ → 시스템종료 → [시스템 종료]: 잠깐 뒤 프로그램이 끝난다
12. 창 가장자리를 끌어 크기를 바꿀 수 있는지 (프레임 없는 창이라 확인 필요, 스펙에 정의 없음)
13. 1366×768 화면 또는 배율 125~150%: 창이 화면보다 커서 헤더가 잘리는지
14. 한글 앱 이름으로 실행 파일 · 바로가기가 정상인지
