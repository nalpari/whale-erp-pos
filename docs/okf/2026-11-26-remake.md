# 목표
잘못 만들었거나 고객이 다시 만들어 달라고 할 때 점원이 [재제조]를 눌러 사유를 남기고 「[재제조]」 주문서를 다시 뽑는다. 주문 상태와 금액은 바뀌지 않는다.[^spec]

# 작업 내용
- 요약 팝업 · 주문내역 상세에서 제조완료와 오늘 결제한 픽업완료 주문에 [재제조] 버튼(강조 없음)이 생겼다. 순서는 [주문취소] [재제조] [다음 단계★].
- 「재제조하시겠습니까?」 팝업: 다시 만들 메뉴(체크 + 수량 1 ~ 주문 수량, 처음엔 모두 해제)와 사유 4개 + 직접 입력 50자(줄바꿈 없음). 메뉴나 사유를 안 고르면 [재제조]가 막힌다. 서버가 고른 메뉴 · 수량으로 재고를 맞춘다(가정).
- 성공하면 「#12 재제조를 등록했습니다.」, 누른 PC의 「주문서」 프린터 모두로 맨 위 「[재제조] HH:mm」 · 「사유: …」 주문서를 고른 메뉴 · 수량만으로 뽑는다. 상태 · 금액은 그대로다.
- 실패면 팝업과 고른 사유가 남고 주문서는 안 나간다. 거절(취소됨 · 0시 지남)이면 팝업을 닫고 「#12 재제조할 수 없는 주문입니다.」.
- 주문내역 상세 처리 이력에 재제조마다 줄(사유 + 「메뉴 × 수량」)이 쌓인다.
- 위젯은 바꾸지 않았다.
