# 목표
[주문내역] 탭에서 최근 한 달 주문을 기간 · 상태 · 검색으로 찾고, 한 건의 결제 정보 · 처리 이력을 본다. 완료 기준은 스펙 9장 1~6[^spec].

# 작업 내용
- [주문내역] 탭이 자리표시 대신 실제 화면이 됐다. 처음 열면 오늘
- 기간: [오늘] [어제] [이번 달] [최근 한 달], 직접 만든 달력(하루 · 기간 + [확인], 범위 밖 날짜 흐림 + 「이전 내역은 웨일ERP에서 볼 수 있습니다.」), `<` `>`는 기간 길이만큼 · 범위 끝은 막음. 며칠 켜 둬 고른 기간이 범위를 벗어나면 오늘로 되돌림
- 검색: 휴대폰 끝 4자리 · 픽업번호(#343 / 343) · 주문번호, 한 달 전체에서 찾고 「최근 한 달에서 검색한 결과입니다」. 검색칸은 숫자 자판
- 탭: 전체 · 접수대기 · 제조중 · 제조완료 · 픽업완료 · 취소(매장취소 + 고객취소), 건수, 요약 줄(「총 9건 · 결제 합계 ₩26,100 (취소 1건 제외)」 등)
- 목록: 픽업번호 · 고객 · 「아메리카노 외 2개」 · 결제금액 · 상태(색) · 주문일시, 접수대기 행 노란 배경, 최신 위, 20 / 50 / 100건(PC 기억), 페이지, 빈 결과 · 실패 [다시 시도] · 「새로 고침」
- 상세: 메뉴 · 단가 · 옵션 금액 · 합계, 기본 정보(16자리 주문번호, 연락처 「***-****-1234」, 「N번째 주문」 · 「첫 주문」), 요청사항, 결제정보(쓴 할인만), 처리 이력(결제 · 제조중 · 제조완료 · 픽업완료 시각, 취소면 시각 · 누가 · 사유), T05 규칙의 상태 버튼(인쇄는 회색 막힘, 취소 주문은 [영수증 인쇄]만). [← 이전]이면 조건 · 페이지 · 스크롤 유지, 다른 탭에 갔다 와도 유지
- 모의 서버가 최근 한 달 예시 주문을 만들고 취소 사유를 기록한다
