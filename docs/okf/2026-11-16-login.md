# 목표

점원과 점주가 두 가지 계정으로 로그인하고, 계정 종류에 따라 바꿀 수 있는 것이 달라진다. 점포번호 계정은 자동 로그인으로 로그인 화면을 건너뛸 수 있다.[^spec]

완료 기준 (스펙 9장):

1. 점포번호 · 마스터 계정이 모의 서버에서 로그인되고 실패 문구가 기획서와 같다
2. `canEditSettings`: 점포번호 거짓, 마스터 참
3. 마스터 탭에서 자동로그인 · 점포번호 찾기가 보이지 않는다
4. 자동 로그인: 재실행 시 건너뜀, 만료 시 로그인 화면 + 토큰 삭제, 로그아웃 시 삭제
5. 점포번호 찾기의 실패 문구 · 완료 화면 · 버튼 동작이 기획서와 같다
6. 휴대폰 번호가 PC 저장소와 로그에 남지 않는다
7. ① 통과, ② · ③ 리뷰 완료

# 작업 내용

- 로그인 화면: 점포 번호 탭(점포 고유번호 + 대표 휴대폰 번호, 숫자만 입력, 눈 아이콘, 자동로그인, 점포번호 찾기)과 마스터 계정 탭. 두 칸이 차야 로그인 버튼이 눌리고, 실패 · 네트워크 오류 문구를 보인다.
- 점포번호 찾기 팝업: 대표자 이름 · 대표 이메일로 찾고, 실패 문구 두 줄 또는 완료 화면(가려진 번호, [로그인] [닫기]).
- 권한: 점포번호 계정은 `canEditSettings` 거짓, 마스터 계정은 참.
- 자동 로그인: 점포번호 계정에서 체크하면 재발급 토큰만 Windows 자격 증명 관리자에 저장한다. 시작할 때 토큰으로 다시 로그인하고, 확인하는 동안 빈 화면을 보인다. 만료 · 폐기면 토큰을 지우고, 네트워크 오류면 남긴다. 로그아웃하면 지운다.
- T01의 개발용 모의 로그인을 실제 로그인 화면으로 바꿨다. 로그인 API는 인터페이스 뒤의 모의 구현이다.

## Windows 확인 체크리스트 (사용자 확인 대기)

1. 자동로그인 체크 후 로그인 → 시스템종료 → 재실행하면 로그인 화면 없이 주문접수 화면이 나온다
2. Windows 자격 증명 관리자 → Windows 자격 증명에 `com.whale.pickuporder.dev` 항목이 있고, 휴대폰 번호는 어디에도 없다
3. 로그아웃 → 재실행하면 로그인 화면이 나오고 자격 증명 항목이 사라진다
4. 체크하지 않고 로그인하면 남아 있던 항목이 사라진다
5. 인터넷을 끊고 재실행하면 로그인 화면이 나오고 항목은 남는다. 다시 연결하고 재실행하면 자동 로그인된다
6. 로그아웃 직후 바로 체크하고 다시 로그인 → 재실행하면 자동 로그인된다 (Rust 명령 순서)
7. 휴대폰 번호 · 마스터 비밀번호 칸에서 비밀번호 저장 제안이나 자동완성이 뜨지 않는다 (눈 아이콘으로 보이게 한 상태 포함)
8. Enter 키로 로그인된다
