## 범위 주의

처음 범위에 없던 기능이다. 2026-11-16에 `AGENTS.md` 범위에 넣었다. 화면정의서 v0.8에서 추가됐다 (이력: "AI챗봇용 인기상품 추가"). AI 챗봇 자체는 고객 앱 쪽 기능이고, 이 프로그램은 **챗봇에 보여 줄 메뉴를 고르는 화면만** 만든다.

## 목표

점주가 고객 앱의 AI 챗봇 "인기 메뉴"에 나올 메뉴를 최대 5개까지 고른다.

## 설명과 그림이 다름 (Q48)

| | p.20 설명 | p.20~21 그림 |
|---|---|---|
| 고르는 방법 | 판매 중인 전체 메뉴 목록에서 체크 상자로 선택/해제 | 고른 메뉴만 목록에 보이고, [+인기상품 추가] 팝업에서 추가, [삭제]로 제거 |
| 개수 표시 | 오른쪽 위 파란 배지 "선택 N / 5개" | 없음 |
| 저장 | [저장] 버튼 → 서버 저장 → 완료 알림(토스트) | 저장 버튼 없음 |

**확정 전에는 만들지 않는다.** 아래는 양쪽에 공통인 내용이다.

## 공통 내용

- 안내 문구: "AI챗봇 인기메뉴에 노출할 메뉴를 추가합니다. 최대 5개까지 설정할 수 있습니다."
- 최대 5개. 5개를 고르면 더 고를 수 없다.
- 목록 열: 상품명, 메뉴/옵션, 카테고리, 금액, 삭제.
- 고객 앱 챗봇에서 [인기 메뉴]를 누르면 설정한 메뉴가 나온다.

## 인기상품 추가 팝업 (p.21, 그림 기준)

- 상품명 검색, 카테고리 탭(+ 옵션 탭), 상품 목록, "N개 선택됨", [닫기] [추가하기].
- 대상: "옵션상품 제외, 품절상품 제외, 일시품절상품 포함". 그림에서는 일시품절 상품이 고를 수 없게 되어 있어 문장과 맞지 않는다.
- 설명 1~4번은 비어 있다.

## 필요한 데이터 · API (가정, 백엔드 협의 전)

- 인기 메뉴 조회·저장 API. 기존 요청 문서에 없는 항목이다.

## 완료 기준 (Q48 답변 뒤 확정)

- 5개를 넘겨 고를 수 없다.
- 저장한 목록이 다시 열었을 때 그대로 보인다.
