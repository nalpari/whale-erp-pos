# T15. 자동 업데이트

- **출처**: 화면정의서에 없음. `AGENTS.md` 범위("자동 업데이트")와 확정 사항 "화면 배포 방식: 화면 내장(A-2)"
- **선행 태스크**: T16 (설치 파일)
- **크기(추정)**: 중
- **관련 문의**: 없음 (배포 서버 위치는 백엔드 · 운영과 협의 필요)

## 목표

화면을 설치 파일에 넣었으므로(A-2), 수정 사항은 자동 업데이트로만 매장 PC에 배포할 수 있다. 새 버전을 확인하고 받아 설치하는 흐름을 만든다.

## 알고 있는 것 (기술 리서치, `docs/research/store-order-receiver-tech-research.md`)

- Tauri 업데이터는 서명이 필수이며 끌 수 없다. 서명 키를 잃어버리면 이미 설치된 앱에는 업데이트를 더 배포할 수 없다.
- Windows에서는 설치 단계에서 앱이 자동으로 종료된다.
- 위 내용은 2026-11-12 리서치 기준이다. 스펙 단계에서 공식 문서로 다시 확인한다.

## 정해야 하는 것 (스펙 단계)

- 업데이트 파일을 어디에 올리는지 (서버 · 저장소). 백엔드 · 운영 담당과 협의.
- 서명 키 보관 방법 (잃어버리면 복구할 수 없음).
- 언제 설치하는지: 주문이 몰리는 시간에 앱이 꺼지면 안 된다 (설계 원칙 3). 영업 중 설치를 막거나 미루는 규칙이 필요하다.
- 새 Tauri 플러그인 추가 승인.

## 완료 기준

- 새 버전이 있으면 알고, 정한 시점에 받아 설치한다.
- 영업 중(주문받기 ON 등)에는 앱이 갑자기 꺼지지 않는다.
- 서명이 맞지 않는 업데이트는 설치하지 않는다.
