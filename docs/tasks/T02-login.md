# T02. 로그인 · 점포번호 찾기

- **출처**: 화면정의서 v0.8 p.8(점포 번호 로그인), p.9(마스터 계정 로그인), p.10(점포번호 찾기 팝업)
- **선행 태스크**: T01
- **크기(추정)**: 중
- **관련 문의**: Q09, Q10, Q11, Q12, Q13, Q14, Q15

## 목표

두 가지 계정(점포번호, 마스터)으로 로그인하고, 계정 종류에 따라 접근 범위를 나눈다.

## 계정 종류

| | 점포번호 계정 | 마스터 계정 |
|---|---|---|
| 정식 이름 | 픽업오더 매장 프로그램 계정 | 파트너오피스 ERP 마스터 계정 |
| 아이디 | 점포 고유번호 (ERP가 자동 부여, 고정) | ERP 아이디 (파트너오피스와 같음) |
| 비밀번호 | 대표 휴대폰 번호 | ERP 비밀번호 (파트너오피스와 같음) |
| 접근 범위 | 주문접수 · 주문내역 · 매장정보 · 메뉴품절 | 전체 탭 + 환경설정 전체 |
| 환경설정 | 위젯·프린터 **조회만** (변경 불가) | 변경 가능 |
| 자동 로그인 | 가능 | 없음 (화면에서 숨김) |
| 점포번호 찾기 | 있음 | 없음 (화면에서 숨김) |

## 화면 요소와 동작

### 점포 번호로 로그인 (기본 탭, p.8)

1. 탭: [점포 번호로 로그인] [마스터 계정으로 로그인]. 기본은 점포 번호.
2. 점포 고유번호 입력 칸.
3. 대표 휴대폰 번호 입력 칸. 입력값을 가리고, 눈 아이콘으로 표시/숨김을 바꾼다.
4. 자동로그인 체크 상자. 체크하면 다음 실행 때 자동 로그인하고, 해제하면 매번 로그인한다.
5. [점포번호 찾기] → 점포번호 찾기 팝업.
6. [로그인] → 성공하면 주문접수 화면으로 이동한다.
   - 실패하면 "! 아이디와 비밀번호가 올바르지 않습니다."를 표시한다.
   - 대표 휴대폰 번호로 로그인하면 대표 휴대폰으로 로그인 알림이 간다: "[픽업오더 주문접수 프로그램 로그인 알림] [PC번호] 에서 로그인했습니다." (발송은 서버 담당, Q11)

### 마스터 계정으로 로그인 (p.9)

1. 마스터 아이디, 마스터 비밀번호(가림 + 눈 아이콘), [로그인].
2. 자동로그인과 점포번호 찾기는 보이지 않는다.
3. 실패 문구는 점포 번호 로그인과 같다.

### 점포번호 찾기 팝업 (p.10)

1. 안내: "파트너오피스에 등록된 대표 이메일로 점포번호를 찾을 수 있습니다."
2. 대표자 이름, 대표 이메일 입력.
3. [점포번호 찾기] → 조회. 실패 문구: "파트너오피스에 일치하는 정보가 없습니다. 대표자 이름과 이메일을 확인 후 다시 시도해 주세요."
4. 성공하면 완료 상태로 바뀐다: "{점포명} 님의 점포번호 찾기가 완료되었습니다." + 가려진 점포번호(예: HC-1\*\*\*4-PO).
5. [로그인] → 찾은 점포번호로 로그인 화면으로 이동. [닫기]/[취소]/× → 팝업 닫기.

## 필요한 데이터 · API (가정, 백엔드 협의 전)

- 점포번호 로그인, 마스터 로그인, 점포번호 찾기 API. 응답에 계정 종류(권한)와 점포 정보가 있어야 한다.
- 기존 요청 문서(`docs/requests/backend-api-request.md`)는 "매장 코드로 기기 등록" 방식을 가정했다. 화면정의서의 로그인 방식으로 **다시 써야 한다.**
- 자동 로그인에 쓸 토큰의 유효 기간과 갱신 방법. 매장 PC는 며칠씩 켜 둔다.

## 기획서에 없어서 정해야 하는 것

- 마스터 계정에 점포가 여러 곳일 때의 점포 선택 (Q09).
- 가려진 점포번호로 어떻게 로그인하는지 (Q12).
- 동시 로그인, 로그인 실패 잠금 (Q13).

## 개발 담당자 의견 (기획자에게 전달 권장)

- 비밀번호가 대표 휴대폰 번호다. 휴대폰 번호는 직원·거래처가 알기 쉬운 값이라, 점포번호만 알면 누구나 주문을 접수·거부·취소할 수 있다. 로그인 알림이 보완책으로 보이지만, 별도 비밀번호나 PC 등록 절차를 검토할 만하다. 확정된 문제가 아니라 의견이다.

## 완료 기준

- 두 계정으로 로그인하고, 점포번호 계정에서는 환경설정을 바꿀 수 없다.
- 자동로그인을 체크하면 재실행 때 로그인 화면을 건너뛴다.
- 오류 문구가 기획서와 같다.
- 점포번호 찾기의 성공·실패 흐름이 동작한다 (모의 서버 기준).
