# T06. 바탕화면 주문 알림 위젯 · 알림음

- **출처**: 화면정의서 v0.8 p.7(위젯 화면정의), p.18(위젯설정), p.24(반복 알림)
- **선행 태스크**: T03, T05
- **크기(추정)**: 대
- **관련 문의**: Q20, Q30, Q31, Q32, Q33, Q44

## 목표

프로그램 창이 최소화됐거나 다른 창(기존 POS 등) 뒤에 있어도 새 주문을 놓치지 않게, 바탕화면 구석에 작은 창과 알림음으로 알린다.

## 화면 요소 (기획서 기준)

| 요소 | 내용 |
|---|---|
| 접수대기 카드 | 머리 "접수대기" / "주문시간 13:21 \| 지금픽업" / 픽업번호 / `>` / 메뉴·옵션·수량 / [주문거부] [주문접수] |
| 제조중 카드 | 머리 "제조중" / 주문시간, 픽업예정, 픽업번호 / 요청사항(노란 강조) / 메뉴 / [제조완료] |
| 위치 | 기본 우측 하단. 설정에서 우상단·좌상단·우하단·좌하단 중 선택 (T10) |

## 동작 규칙

1. 프로그램이 최소화됐거나 다른 창 뒤에 있어도, 새 주문이 오면 위젯이 자동으로 뜬다.
2. 최신 주문은 아래에 쌓이고 오래된 주문이 위에 온다. 직접 닫을 때까지 유지한다.
3. [주문접수] → 주문서 자동 출력 → 고객 앱 알림 "주문이 접수되었습니다."
4. [주문거부] → 취소 사유 팝업(T05) → 주문 취소 처리, 카드 닫힘 → 고객 앱 알림 "매장사정으로 주문이 취소되었습니다."
5. 카드를 누르면 주문접수 화면을 앞으로 가져오고 해당 주문을 활성화한다.
6. 어떤 상태의 카드를 위젯에 보일지는 설정을 따른다. 접수대기는 항상 보인다 (T10).
7. 새 주문에 알림음을 낸다. 접수하지 않으면 반복해서 알린다 (간격·종료 조건 미정, Q20).

## 기술 참고 (스택 확정: Tauri + Vite + React, 화면 내장)

- 위젯은 본 창과 별개의 창이다. 항상 위에 떠 있고, 작업표시줄에 따로 나타나지 않아야 한다.
- 본 창과 위젯이 같은 주문 목록을 봐야 한다. 한쪽에서 접수하면 다른 쪽에도 바로 반영한다.
- 구현 방법은 스펙 단계에서 Tauri 공식 문서로 확인한 뒤 정한다. 아직 확인하지 않았다.

## 기획서에 없어서 정해야 하는 것

- 닫는 방법과, 닫은 뒤 다시 뜨는 조건 (Q30). 접수하지 않은 주문의 위젯을 닫고 잊으면 주문 누락과 같다.
- 카드가 많을 때의 처리 (Q31).
- 알림음 종류와 크기 0 허용 여부 (Q44).

## 사용자에게 요청할 실물 확인

- 매장 스피커에서 알림음이 충분히 크게 들리는지.
- 기존 POS 프로그램이 전체 화면일 때도 위젯이 위에 보이는지.

## 완료 기준

- 본 창을 최소화한 상태에서 새 주문이 오면 위젯이 뜨고 알림음이 난다.
- 위젯에서 접수·거부하면 본 창의 카드에도 반영된다.
- 같은 주문에 위젯 카드와 알림음이 한 번만 나온다 (반복 알림 제외).
