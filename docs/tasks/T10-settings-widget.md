# T10. 환경설정 — 위젯설정 · 알림음

- **출처**: 화면정의서 v0.8 p.18
- **선행 태스크**: T06
- **크기(추정)**: 소
- **관련 문의**: Q10, Q15, Q44

## 목표

바탕화면 위젯에 어떤 주문을 어디에 보일지, 알림음을 얼마나 크게 낼지 정한다.

## 화면 요소와 동작 (기획서 기준)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 하위 탭 | 위젯설정 / 프린터설정 / AI챗봇 인기메뉴 설정. 기본은 위젯설정 |
| 2 | 표시할 주문 상태 | 접수대기: 항상 표시(고정, 바꿀 수 없음). 제조중·제조완료·픽업완료: 체크로 표시 여부 |
| 3 | 위젯 위치 | 우상단 / 좌상단 / 우하단(기본) / 좌하단. 고르면 미리보기에 바로 반영 |
| 4 | 알림음 | 슬라이더로 크기 조절. [미리듣기]로 지금 알림음 확인. 알림음 종류(새주문 / 픽업자 근처 도착 등)는 **추후 정의** |
| 5 | 상태별 위젯 미리보기 | 지금 설정의 결과를 오른쪽에서 확인. `<` `>`로 상태를 넘김 |
| 6 | [저장] | 바뀐 설정 저장 |

- 화면 제목: "바탕화면에 주문 알림 위젯을 표시합니다."
- 점포번호 계정은 조회만 할 수 있다 (p.8).

## 기획서에 없어서 정해야 하는 것

- 설정을 PC에 저장할지 서버에 저장할지 (Q15). 위젯 위치와 알림음 크기는 PC마다 다르므로 PC 저장이 자연스럽다. 확정이 아니라 개발 담당자 의견이다.
- 알림음 크기의 최솟값 (Q44).

## 완료 기준

- 저장한 설정이 재실행 뒤에도 유지되고 위젯(T06)에 반영된다.
- 접수대기 체크는 풀 수 없다.
- 점포번호 계정에서는 값을 바꿀 수 없다.
- 미리듣기가 지금 크기로 소리를 낸다.

## 결정 사항 (2026-11-17 사용자)

- 점포번호 계정이면 화면 맨 위에 "위젯 설정은 마스터 계정만 변경할 수 있습니다." 같은 안내 줄을 계속 보인다 (T11 프린터설정과 같은 방식, 팝업 아님). 정확한 문구는 T10 스펙에서 정한다.
- 알림음 크기 (2026-11-19 사용자, T06 실제 창 확인 뒤): T06의 지금 소리(파형 최대 0.5)를 크기 설정 **40**으로 본다. 기본값 40, 설정에서 100까지 키울 수 있다(100은 지금의 2.5배 → 2026-11-19 구현 중 「2배」로 바꿈, 스펙 11장 D). 최소 20%(Q44). 크게 했을 때 소리가 찢어지지 않게 하는 방법은 T10 스펙에서 정한다.
