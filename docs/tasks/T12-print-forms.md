# T12. 출력 — 주문서 · 영수증

- **출처**: 화면정의서 v0.8 p.22(출력양식 - 주문서), p.23(출력양식 - 영수증)
- **선행 태스크**: T11, T03
- **크기(추정)**: 대
- **관련 문의**: Q45, Q47, Q49, Q50

## 목표

접수하면 주문서를 자동으로 뽑고, 필요할 때 주문서와 영수증을 다시 뽑는다.

## 주문서 (p.22)

- **자동 출력**: [주문접수]를 누르면 설정된 프린터로 출력한다.
- **수동 출력**: [주문서 인쇄]를 누르면 출력한다.

| 번호 | 영역 | 내용 |
|---|---|---|
| 1 | 머리 | "픽업오더 주문서 (주방 / 바리스타용)", 픽업번호(크게), 주문번호, 주문일시, 주문자(가린 이름 + 가린 연락처), 픽업예정 |
| 2 | 요청사항 | 있으면 강조해서 출력, 없으면 출력하지 않음 |
| 3 | 메뉴 | 메뉴명, 옵션(아랫줄에 ㄴ), 수량 |
| 4 | 구분선 | 메뉴마다 선으로 구분 |

## 영수증 (p.23)

- **출력**: [영수증 인쇄]를 누를 때. 프린터 설정에서 "영수증 (고객 요청 시)"이 체크된 경우에만 버튼이 활성화된다.

| 번호 | 영역 | 내용 |
|---|---|---|
| 1 | 점포 정보 | 점포명, 전화번호, 주소, 대표자, 사업자번호, 판매일자, 주문번호 |
| 2 | 메뉴 및 금액 | 메뉴명, 옵션, 수량, 금액 / 주문금액, 할인금액, 결제금액, 과세금액, 부가세 |
| 3 | 카드 결제 정보 | 카드번호(가림), 거래종류, 거래구분, 승인번호, 승인일시, 매입사명 |
| 4 | [영수증 인쇄] [닫기] | 연결된 프린터로 출력 / 팝업 닫기 |

## 설계 원칙과의 관계

- **중복 출력 방지**: 같은 주문의 자동 출력은 한 번만 한다 (`AGENTS.md` 설계 원칙 2번). 위젯과 본 창에서 동시에 접수를 눌러도 한 장만 나와야 한다.
- **서버 성공 뒤 출력**: 접수 요청이 성공한 뒤에만 주문서를 출력한다.
- **출력 실패**: 화면 정의가 없다 (Q47). 최소한 실패를 알리고 다시 출력할 수 있어야 한다.

## 필요한 데이터 (가정, 백엔드 협의 전)

- 영수증에는 사업자 정보와 카드 승인 정보가 필요하다. 기존 요청 문서에서 요청하지 않은 항목이다. **결제 정보를 매장 프로그램이 받는 것**이므로 백엔드와 범위·보안을 협의해야 한다.
- 영수증이 세금 증빙으로 인정되는 양식인지는 확인하지 못했다. 기획자·대표님 확인이 필요하다.

## 미결정 사항과의 관계

- 출력 방식(드라이버 vs 포트 직접), 프린터 모델, 용지 폭이 정해지지 않았다. 양식 배치는 폭에 따라 달라진다. 가상 프린터로 먼저 만든다.

## 사용자에게 요청할 실물 확인

- 한글이 깨지지 않는지, 줄바꿈과 정렬이 그림과 같은지, 용지가 잘리는지(커팅).
- 긴 메뉴명·긴 요청사항이 잘리지 않는지.

## 완료 기준

- 접수하면 주문서가 한 장 나오고, 같은 주문을 다시 접수 처리해도 자동 출력은 반복되지 않는다.
- 요청사항이 없으면 그 줄이 없다.
- 영수증 체크를 끄면 [영수증 인쇄]가 눌리지 않는다.
- 가상 프린터 출력물이 기획서 양식의 항목을 모두 담는다.
