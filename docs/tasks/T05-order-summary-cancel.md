# T05. 주문 요약 팝업 · 거부/취소 팝업

- **출처**: 화면정의서 v0.8 p.12(주문 요약 정보 팝업), p.7(취소 사유 팝업)
- **선행 태스크**: T04
- **크기(추정)**: 중
- **관련 문의**: Q16, Q17, Q18, Q27, Q28

## 목표

카드를 누르면 주문 한 건의 자세한 내용을 보여 주고, 인쇄·취소·다음 단계 처리를 한다.

## 주문 요약 팝업 (p.12)

여는 법: 주문접수 화면에서 카드 클릭. 닫는 법: × 버튼 또는 어두운 바깥 영역 클릭.

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 팝업 헤더 | 픽업번호, 현재 주문 상태, × |
| 2 | 처리 단계 | 주문접수 → 제조시작 → 제조완료 → 픽업완료. 끝난 단계는 체크와 완료 시각(시:분), 현재 단계는 강조 |
| 3 | 주문 기본정보 | 주문일시, 주문번호, 픽업예정(예: "15:45 (15분뒤)"), 고객명(가림), 연락처(가림) |
| 4 | 요청사항 | 있으면 강조, 없으면 표시하지 않음 |
| 5 | 주문 메뉴 목록 | 메뉴명, 수량. 옵션은 쉼표로 한 줄(예: "디카페인 x1, 헤이즐넛 x2") |
| 6 | [영수증 인쇄] [주문서 인쇄] [주문취소] | 영수증·주문서 출력(T12). 주문취소는 **접수대기·제조중일 때만** 활성. 제조완료·픽업완료에서는 비활성 ("이미 완성된 음료·음식은 취소 처리 불가") |
| 7 | 다음 단계 버튼 | 제조중이면 [제조완료], 제조완료 뒤에는 [픽업완료]로 바뀜 |

- 접수대기 상태의 버튼 구성은 기획서에 없다 (Q27).

## 거부 / 취소 사유 팝업 (p.7)

| 요소 | 내용 |
|---|---|
| 제목 | "주문을 취소하시겠습니까?" |
| 안내 | "취소사유를 선택하세요." |
| 선택 1 | "매장 사정으로 주문을 취소합니다." (기본 선택) |
| 선택 2 | "직접 입력" + 입력 칸 |
| 버튼 | [닫기] [주문 취소] |

- 확인하면 주문을 취소 처리하고, 고객 앱에 "매장사정으로 주문이 취소되었습니다."가 간다 (서버 담당).
- 카드의 [거부], 위젯의 [주문거부], 요약 팝업·상세의 [주문취소]가 이 팝업을 같이 쓰는지는 확정되지 않았다 (Q17).

## 기획서에 없어서 정해야 하는 것

- 제조시작 시각의 기록 시점 (Q16).
- 사유 선택지와 글자 수 (Q18).
- 취소를 눌렀는데 그 사이 고객이 먼저 취소한 경우의 안내. 서버 응답에 맞춰 정한다.

## 완료 기준

- 4개 상태마다 단계 표시, 활성 버튼이 기획서와 같다.
- 제조완료·픽업완료 주문에서 [주문취소]가 눌리지 않는다.
- 사유를 고르거나 입력한 뒤에만 취소가 진행되고, 서버가 성공을 돌려준 뒤 카드가 사라진다.
