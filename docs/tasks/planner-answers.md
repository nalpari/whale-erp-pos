- Q62: [재제조]는 제조완료 · 픽업완료(그날)에서 누른다. 사유를 고르면 「[재제조]」 주문서를 다시 뽑고 기록만 남긴다. 주문 상태는 바뀌지 않는다. 사유는 정해진 문구 몇 개 + 직접 입력으로 받되, 문구 목록은 아직 정하지 않았다.
- (이어서 같은 날) 픽업완료 뒤 매장 취소는 **결제한 날 0시 전까지**만 된다. 「환불」은 주문내역 「취소」 탭에 같이 넣고 상태 글자만 「환불」로 보이며, 상세 처리 이력에 누가 취소했는지와 환불 시각을 보인다. 재제조 사유는 지휘 세션 초안 「메뉴를 잘못 만들었습니다 / 맛 · 품질 문제 / 이물질 / 고객 주문 실수 / 직접 입력」으로 시작하고, 나중에 더한다.
