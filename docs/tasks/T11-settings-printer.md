# T11. 환경설정 — 프린터설정

- **출처**: 화면정의서 v0.8 p.19
- **선행 태스크**: T01, T02
- **크기(추정)**: 중 (출력 방식에 따라 달라짐)
- **관련 문의**: Q15, Q45, Q46, Q47

## 목표

주문서와 영수증을 어느 프린터로 낼지 정한다. 프린터는 최대 3대까지 등록한다.

## 화면 요소와 동작 (기획서 기준)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 프린터설정 탭 | |
| 2 | 프린터 슬롯 | **최대 3대.** 슬롯마다 프린터 이름과 용도 이름(예: "카운터 영수증", "주방 주문서"). 용도 이름 옆에 수정(연필) 버튼 |
| 3 | 출력 항목 | 주문서: 주문접수 때 자동 출력 여부. 영수증(고객 요청 시): 출력 여부 |
| 4 | [연결 해제] | 그 슬롯의 프린터 연결을 푼다 |
| 5 | [+ 프린터 추가] | 빈 슬롯에서 누르면 프린터 목록에서 고른다 |

화면 아래 안내 "프린터 추가 방법"

1. 프린터를 USB 또는 네트워크로 PC에 연결합니다
2. Windows 프린터 드라이버를 설치합니다
3. '+ 프린터 추가' 버튼 클릭 → 목록에서 해당 프린터를 선택합니다

그림의 예: 슬롯 1 — BIXOLON SRP-350V, 슬롯 2 — EPSON TM-T82X, 슬롯 3 — 프린터 없음.

## 미결정 사항과의 관계 (중요)

- 화면정의서는 **Windows에 드라이버로 설치된 프린터 목록에서 고르는 방식**을 전제한다. `AGENTS.md` "미결정 사항"의 "출력 방식 (드라이버 vs 포트 직접)" 중 드라이버 쪽이다.
- 리서치 결과, Windows 출력 대기열을 거치면 용지 없음 같은 프린터 상태를 프로그램이 알기 어렵다 (`docs/research/store-order-receiver-tech-research.md`). 주문서가 안 나온 것을 모르면 주문 누락과 같으므로 Q47의 답이 필요하다.
- 프린터 모델·연결 방식은 대표님 확인을 기다리는 중이다 (`docs/questions/ceo-store-environment.md`). 그림의 두 모델은 예시로 보이며, 실제 매장 모델로 확정된 것이 아니다.
- 따라서 이 태스크의 화면은 만들 수 있지만, **출력 방식은 가정으로 두고** 확정 뒤 다시 본다.

## 기획서에 없어서 정해야 하는 것

- 주문서가 체크된 프린터가 여러 대일 때의 동작, 저장 방식, 시험 인쇄, 용지 폭 (Q45).
- 설명 문장과 그림의 차이 (Q46).
- 설정 저장 위치 (Q15). 프린터는 PC에 붙어 있으므로 PC 저장이 자연스럽다. 개발 담당자 의견이다.

## 사용자에게 요청할 실물 확인

- 실제 매장 프린터가 목록에 나타나는지, 시험 인쇄가 나오는지.

## 완료 기준

- Windows에 설치된 프린터 목록이 나오고 슬롯 3개에 등록·해제할 수 있다.
- 슬롯별 출력 항목 설정이 주문서·영수증 출력(T12)에 반영된다.
- 점포번호 계정에서는 값을 바꿀 수 없다.
- 가상 프린터(PDF 등)로 등록부터 출력까지 확인한다.
