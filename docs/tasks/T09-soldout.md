# T09. 메뉴품절 · 품절상품 추가 팝업

- **출처**: 화면정의서 v0.8 p.16(메뉴품절), p.17(품절상품 추가 팝업)
- **선행 태스크**: T01, T02
- **크기(추정)**: 중
- **관련 문의**: Q41, Q42, Q43

## 범위 주의

처음 범위에 없던 기능이다. 화면정의서에 따라 2026-11-16에 `AGENTS.md` 범위에 넣었다. 재고 관리가 아니라 "앱에서 팔지 않게 표시"하는 기능이다.

## 목표

재료가 떨어진 메뉴·옵션을 매장에서 바로 품절로 바꿔, 고객이 주문하지 못하게 한다.

## 메뉴품절 (p.16)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 안내 문구 | "품절 상품을 삭제하면 해당 상품이 앱에서 다시 판매 가능 상태로 변경됩니다." |
| 2 | 상태 탭 | 전체 / 일시품절 / 숨김. 탭마다 건수 |
| 3 | 품절 상품 목록 | 상품명, 메뉴/옵션 구분, 카테고리, 금액, 표시방식, 삭제 |
| 4 | [+ 품절 상품 추가] | 추가 팝업을 연다 |
| 5 | [삭제] | 확인 문구 "품절상품을 삭제하시겠습니까?" → 목록에서 빼고 앱에서 다시 판매 |

- 표시방식은 둘 중 하나를 고른다.
  - **일시 품절**: 앱에 보이고 "품절"로 표시
  - **숨김**: 앱에 보이지 않음
- 최근에 추가한 상품이 위에 온다.

## 품절상품 추가 팝업 (p.17)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 상품명 검색 | 팝업 안에서 상품명으로 거른다 |
| 2 | 카테고리 탭 | 카테고리를 누르면 그 상품만 표시. [옵션] 탭은 옵션 항목만 |
| 3 | 상품 목록 | 상품명, 메뉴/옵션 구분, 카테고리, 금액. 이미 품절 등록된 항목은 체크 상자를 막고 "등록됨" 표시 |
| 4 | 선택 정보 | "N개 선택됨"을 바로바로 표시 |
| 5 | [추가하기] | 고른 상품을 품절 목록에 넣는다. **일시품절 상태로 즉시 저장** |
| 6 | [닫기] | 팝업 닫기 |

## 필요한 데이터 · API (가정, 백엔드 협의 전)

- 점포의 상품·옵션·카테고리 목록 조회, 품절 목록 조회·추가·표시방식 변경·삭제 API. 기존 요청 문서에 없는 항목이다.

## 기획서에 없어서 정해야 하는 것

- 표시방식을 바꿀 때 바로 저장하는지 (Q42).
- 품절이 자동으로 풀리는지 (Q41). 풀리지 않으면 다음 날에도 품절로 남는다.

## 완료 기준

- 추가한 상품이 일시품절로 목록 맨 위에 나타난다.
- 이미 등록된 상품은 팝업에서 고를 수 없다.
- 삭제하면 확인 문구가 뜨고 목록에서 빠진다.
- 탭 건수가 목록과 맞는다.
