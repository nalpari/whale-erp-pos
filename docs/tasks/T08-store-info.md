## 범위 주의

처음 범위(주문 수신·접수·출력)에 없던 기능이다. 화면정의서에 따라 2026-11-16에 `AGENTS.md` 범위에 넣었다.

## 목표

고객 앱(픽업오더 앱)에 보이는 점포 소개, 공지, 편의시설 정보를 매장에서 고친다.

## 화면 요소와 동작 (기획서 기준)

| 번호 | 요소 | 내용 |
|---|---|---|
| 1 | 안내 문구 | "매장정보는 픽업오더 앱에 노출됩니다. 대표메뉴는 목록화면에표시되고, 점포 공지, 편의시설 및 서비스는 매장 상세화면에 표시됩니다. 점포공지 및 평의시설 및 서비스 항목의 노출을 끄면 해당 정보는 픽업오더 앱에 노출되지 않습니다." |
| 2 | 점포 소개 | 최대 100자. **필수**이며 비어 있으면 저장할 수 없다. 글자 수 표시 "(50 / 100자)" |
| 3 | 점포 공지 | 최대 200자. 토글로 앱 노출 여부(표시/미표시). ∧/∨ 버튼으로 스크롤 |
| 4 | 편의시설 및 서비스 | 태그 선택. 토글로 앱 노출 여부. 체크된 값만 앱에 표시 |
| 5 | [저장] | 바뀐 내용을 저장하고 앱에 반영 |

편의시설 태그 (그림 기준)

| 구분 | 태그 |
|---|---|
| 결제수단 | 제로페이, 애플페이 |
| 편의 | 주차, 좌석보유, 와이파이, 화장실 |
| 동반 | 반려동물, 유아의자, 유아시설 |
| 운영 | 배달, 연중무휴, 남녀화장실구분 |

- 안내 문구의 "평의시설"은 "편의시설"의 오타로 보인다. 기획자 확인 후 고친다.

## 필요한 데이터 · API (가정, 백엔드 협의 전)

- 매장정보 조회·저장 API. 기존 요청 문서에 없는 항목이다.

## 기획서에 없어서 정해야 하는 것

- 저장하지 않고 다른 탭으로 갈 때의 경고. 기획서에 없다.
- 대표메뉴 설정 위치 (Q38).

## 완료 기준

- 저장한 값이 다시 열었을 때 그대로 보인다.
- 점포 소개가 비어 있으면 저장되지 않는다.
- 100자·200자를 넘겨 입력할 수 없다.
