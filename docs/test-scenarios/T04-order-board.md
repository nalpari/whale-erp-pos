# 테스트 시나리오: T04 주문접수 화면

- **태스크**: T04 주문접수 화면 (Plane WHALEERPPO-5)
- **스펙**: `docs/specs/SPEC-order-board.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: 창 폭 1024 / 1280 / 최대화에서 한 줄 3 / 4 / 6장, 넘칠 때만 이전/다음, 접수 → 제조완료 → 픽업완료 배너 · [완료 취소], [고객 취소] 배너 — 사용자 "잘되네" (2026-11-18, OKF 「검증」)
- **확인하지 못하는 것**: 실제 터치(끌어서 스크롤 · 버튼 누르기), 0시가 지난 뒤 동작(어제 결제한 제조중 · 제조완료 주문이 첫 탭에 남는 것. 2026-11-26 0시 자동 픽업완료 없앰 결정), 고객 도착 시각 표시(대표님 정책 ②, 아직 코드에 없다. 지금 카드는 고객이 고른 픽업 예정 값을 보인다)
- 제조완료 · 픽업완료 주문의 취소는 `T18-cancel-scope.md`, 재제조는 `T21-remake.md`를 본다.

## 준비

| 순서 | 할 일 |
|---|---|
| P1 | 「점포번호로 로그인」 탭에서 점포코드 `ST000001`, 비밀번호 `1234`로 로그인 (모의 계정) |
| P2 | 앱을 새로 켠 직후 화면 왼쪽 아래 「개발용 모의 주문」을 펼치고 [주문 10건]. 모의 주문의 픽업 예정은 #1 「지금」, #2 5분 … #7 1시간 이상 순서로 돌고, 3 · 6 · 9번째가 메뉴 5줄 · 요청사항이 있는 긴 주문이다([전체 주문 삭제] 뒤에는 번호가 #1부터 다시 시작해도 이 순서가 어긋난다) |

## A. 탭 · 정렬 · 필터

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A1 | [주문접수] 탭을 본다 | 안쪽 탭 「접수대기 · 제조중 · 제조완료」 · 「픽업완료」. 필터 체크 「접수대기 10」 「제조중 0」 「제조완료 0」 | |
| A2 | 「정렬」을 「오래된순」으로 → 프로그램을 껐다 다시 켠다(자동 로그인) | 정렬은 「오래된순」 그대로, 필터는 모두 체크 | |
| A3 | 「접수대기」 체크를 끈다 | 접수대기 카드가 숨는다. 다시 켜면 보인다 | |

## B. 카드 내용

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B1 | #1 카드를 본다 | 「#1」(앞자리 0 없음), 「접수대기」 글자, 「지금 픽업」 | |
| B2 | #3 카드(긴 주문)를 본다 | 메뉴 3줄 + 「+ 외 2개」, 옵션 한 줄 말줄임, 노란 요청사항 2줄. 카드 높이가 다른 카드와 같다 | |
| B3 | #2 카드를 본다 | 「HH:mm 픽업 (N분 뒤)」. 예정 시각이 지나면 빨간 「N분 지남」 | |
| B4 | #7 카드를 본다 | 「HH:mm 픽업 (1시간 이상)」 | |
| B5 | 접수하지 않은 카드를 결제 뒤 12분까지 둔다 (12분 기다림) | 「3분 뒤 자동 취소」가 보인다 | |

## C. 상태 변경 · 배너

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| C1 | #1 카드 [주문접수] → [제조완료] | 「제조중」 → 「제조완료」로 바뀌고, 누르는 동안 「처리 중…」 | |
| C2 | [픽업완료] | 화면 아래 배너 「픽업번호 #1 픽업완료 되었습니다.」 + [완료 취소(05)]가 1초씩 줄고 5초 뒤 사라진다. 카드는 「픽업완료」 탭으로 | |
| C3 | 다른 카드로 C1~C2 뒤 배너가 떠 있는 동안 [완료 취소(0N)] | 카드가 첫 탭에 「제조완료」로 돌아온다 | |
| C4 | [고객 취소(가장 오래된 접수대기)] | 카드가 사라지고 배너 「픽업번호 #N 고객이 주문을 취소했습니다.」 5초 | |
| C5 | [주문내역] 탭으로 옮긴 뒤 [고객 취소(가장 오래된 접수대기)] → [주문접수] 탭으로 돌아오기 | 알림음은 한 번 울렸고, 배너는 보이지 않는다 | |

## D. 화면 크기 · 넘김

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| D1 | 창 폭을 1024 / 1280 / 최대화로 바꾼다 (더보기 [창 줄이기] · [창 늘리기], 창 가장자리 끌기) | 한 줄에 카드 3 / 4 / 6장. 카드가 잘리지 않는다 | |
| D2 | 카드가 한 화면을 넘을 때와 안 넘을 때를 본다 | 넘칠 때만 [이전] [다음]이 보이고 한 화면씩 넘어간다 | |
| D3 | 개발 패널 [전체 주문 삭제] | 「처리할 주문이 없습니다.」. 「픽업완료」 탭은 「오늘 픽업완료한 주문이 없습니다.」 | |
