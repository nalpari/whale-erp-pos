- **스펙**: `docs/specs/SPEC-settings-order.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버
- **처음 작성**: 2026-11-27
- **확인하지 못하는 것**: 저장 시간 초과(10초) 뒤 서버에서 다시 읽는 동작은 모의 서버에서 시간 초과를 일으킬 수 없어 가짜 시계 테스트로만 확인했다. 실제 터치스크린, Windows. 모의 서버라 앱을 다시 켜면 설정이 기본값(15분 · 5분)으로 돌아간다. 도착 최소 시간이 고객 앱 선택지에 반영되는지는 앱 · 서버 담당이라 여기서 볼 수 없다
