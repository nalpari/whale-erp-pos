# 테스트 시나리오: T10 위젯설정 · 알림음

- **태스크**: T10 위젯설정 · 알림음 (Plane WHALEERPPO-11)
- **스펙**: `docs/specs/SPEC-settings-widget.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버. 위젯 위치를 보려면 반드시 `GDK_BACKEND=x11`로 켠다(KDE Wayland는 위치를 무시).
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: `GDK_BACKEND=x11`로 확인 순서 1~7(화면 · 크기 20~100 미리듣기 · 위젯 위치 이동 · 표시 상태 · 전체 삭제 · 재시작 뒤 유지)대로 확인, 정상 (2026-11-19, OKF 「검증」)
- **확인하지 못하는 것**: 소리 크기 단계 차이 · 100에서 깨지지 않음 · 20에서도 들림(사람이 귀로 판단. 80 → 90 → 100은 계산상 차이가 작다), 실제 터치로 슬라이더 손잡이 끌기, 화면 배율 125 · 150%에서 위치 여백(Windows 체크리스트)
- 위젯 자체의 동작은 `T06-desktop-widget.md`를 본다.

## 준비

| 순서 | 할 일 |
|---|---|
| P1 | 「점포번호로 로그인」 탭에서 점포코드 `ST000001`, 비밀번호 `1234`로 로그인 (모의 계정). 화면을 한 번 눌러 소리 장치를 깨운다 |
| P2 | 환경설정 탭 → [위젯설정] |
| P3 | 화면 왼쪽 아래 「개발용 모의 주문」을 펼친다 |

## A. 화면 · 저장

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A1 | 화면을 본다 | 제목 「바탕화면에 주문 알림 위젯을 표시합니다.」. 「표시할 주문 상태」: 접수대기는 체크 · 막힘 + 「항상 표시」, 제조중 · 제조완료 체크. 픽업완료 칸 없음. 「위젯 위치」 우하단, 「알림음 크기」 40 | |
| A2 | 제조중 체크를 끈다 | 「저장되었습니다」 토스트 | |
| A3 | 「미리보기」에서 `<` `>`(이전 예시 · 다음 예시)로 제조중 예시 | 예시 카드에 「위젯에 표시 안 함」. 「예시 화면입니다. 실제 주문이 아닙니다.」 | |

## B. 알림음 크기

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B1 | 슬라이더를 20 · 40 · 100으로 옮기며 [새 주문 미리듣기] | 10 단위로 움직이고 숫자가 보인다. 20은 40의 절반, 100은 2배쯤으로 들린다(귀로 판단) | |
| B2 | [경고 미리듣기] | 낮은 음 세 번이 지금 크기로 난다 | |
| B3 | 크기를 100으로 둔 채 [주문 1건] | 실제 새 주문 소리도 100 크기 | |

## C. 위젯에 반영

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| C1 | [주문 1건] → [주문접수] → [주문 1건] → [5초 뒤 주문 1건] → 5초 안에 더보기 [창 최소화] | 위젯에 접수대기 카드만 보이고 제조중 카드(A2에서 끔)는 없다 | |
| C2 | 위젯이 떠 있는 채로 본 창을 열어 「위젯 위치」를 좌상단 · 우상단 · 좌하단 · 우하단으로 바꾼다 | 떠 있는 위젯이 바로 그 모서리(여백 16px)로 옮겨진다 | |

## D. 재시작 · 전체 삭제

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| D1 | 프로그램을 껐다 다시 켠다(자동 로그인) → [위젯설정] | 제조중 끔 · 위치 · 크기가 그대로 | |
| D2 | [주문 10건] → [전체 주문 삭제] | 주문접수 화면 · 위젯이 비고 30초 알림음이 멈춘다. 다음 [주문 1건]은 #1 | |
| D3 | 설정을 기본값(제조중 체크, 우하단, 40)으로 되돌린다 | 바꿀 때마다 「저장되었습니다」 | |
