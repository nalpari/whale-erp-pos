# 테스트 시나리오: T02 로그인

- **태스크**: T02 로그인 (Plane WHALEERPPO-3), 개편판(2026-11-18) 포함
- **스펙**: `docs/specs/SPEC-login.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버 (`createMockAuthApi`)
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: 2026-11-16 Linux `pnpm tauri dev`에서 자동로그인 체크 → 종료 → 다시 켜면 로그인 화면 없이 들어가는 것을 사용자가 확인 (`docs/okf/2026-11-16-login.md`). 개편판 체크리스트 7개는 Windows 확인 대기 (`docs/okf/2026-11-18-login-revision.md`)
- **확인하지 못하는 것**: 서버 연결 실패 문구 「서버에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요.」(앱의 모의 서버는 실패하지 않아 테스트로만 확인). PC 이름 전달(화면에 안 보임). [웨일ERP 열기]의 실제 페이지(주소가 임시값). 한글 입력기를 켠 채 점포코드 칸의 커서 튐 · 터치 버튼 크기.

## 준비

| 항목 | 내용 |
|---|---|
| 실행 | `GDK_BACKEND=x11 pnpm tauri dev` |
| 키링 | 데스크톱에 로그인해 키링(gnome-keyring)이 잠금 해제된 상태. 잠겨 있으면 시작 때 멈추거나 잠금 해제 창이 뜬다 |
| 점포번호 계정 | 점포코드 `ST000001` / 비밀번호 `1234` |
| 웨일ERP 계정 | 아이디 `master-demo` / 비밀번호 `demo1234!` / 점포코드 `ST000001` |
| 오류용 점포코드 | `ST000002` 미구독, `ST000003` 관리 불가(웨일ERP 탭만), `ST000004` 비밀번호 미설정(점포번호 탭만), `ST000005` 잠김 |

## A. 점포번호 탭

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A-1 | 로그인 화면을 본다 | 제목 「로그인」, 탭 「점포번호로 로그인」 「웨일ERP 계정으로 로그인」. 점포번호 탭에 「점포코드 (예: ST000001)」 「매장 프로그램 비밀번호」 칸, 「자동로그인」, 안내 「점포코드와 매장 프로그램 비밀번호는 웨일ERP 점포 상세에서 확인할 수 있습니다.」 | |
| A-2 | 점포코드에 ` st000001 `(앞뒤 공백, 소문자)을 넣는다 | 「ST000001」로 바뀐다. 20자보다 길게 넣을 수 없다 | |
| A-3 | 비밀번호를 넣고 눈 아이콘을 누른다 | 가려진 글자가 보였다 다시 가려진다. 20자까지만 들어간다 | |
| A-4 | 비밀번호 `9999`로 [로그인] | 「! 아이디와 비밀번호가 올바르지 않습니다.」 | |
| A-5 | 점포코드 `ST000002` / `ST000004` / `ST000005`로 [로그인] | 각각 「픽업오더를 구독한 점포만 사용할 수 있습니다.」 / 「웨일ERP 점포 상세에서 매장 프로그램 비밀번호를 먼저 설정해 주세요.」 / 「로그인이 잠겼습니다. 5분 뒤에 다시 시도해 주세요.」 | |
| A-6 | `ST000001` / `1234`를 넣고 Enter | 로그인되어 주문접수 화면, 헤더에 「모의 점포 (개발용)」 | |

## B. 웨일ERP 계정 탭

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B-1 | 점포번호 탭에 점포코드를 넣은 채 웨일ERP 탭으로 간다 | 점포코드가 그대로 남는다. 「자동로그인」이 없다. 안내 「아이디 · 비밀번호를 잊으셨나요? 웨일ERP에서 찾을 수 있습니다.」와 [웨일ERP 열기] | |
| B-2 | 칸을 하나씩 채운다 | 아이디 · 비밀번호 · 점포코드 세 칸이 다 차야 [로그인]이 눌린다 | |
| B-3 | 점포코드 `ST000003`으로 [로그인] | 「이 계정으로 관리할 수 없는 점포입니다.」 | |
| B-4 | `master-demo` / `demo1234!` / `ST000001`로 [로그인] | 로그인된다 | |
| B-5 | [웨일ERP 열기] | 기본 브라우저가 뜬다 (주소가 임시값이라 페이지는 안 열려도 된다). 앱 화면은 그대로 | |

## C. 점포코드 기억 · 자동 로그인

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| C-1 | 로그인에 성공한 뒤 로그아웃한다 | 로그인 화면 두 탭 모두 점포코드 칸에 마지막 점포코드가 채워져 있다 | |
| C-2 | 「자동로그인」을 체크하고 로그인 → [더보기] → [프로그램 종료] → 다시 켠다 | 잠깐 빈 화면 뒤 로그인 화면 없이 주문접수 화면. 주문받기는 OFF | |
| C-3 | C-2 뒤 [로그아웃] → 다시 켠다 | 로그인 화면이 나온다 | |
| C-4 | 체크하지 않고 로그인 → 종료 → 다시 켠다 | 로그인 화면이 나온다 (남아 있던 토큰이 지워짐) | |
| C-5 | 로그아웃 직후 바로 체크해 다시 로그인 → 종료 → 다시 켠다 | 자동 로그인된다 | |
