# 테스트 시나리오: T07 주문내역 · 상세

- **태스크**: T07 주문내역 · 상세 (Plane WHALEERPPO-8)
- **스펙**: `docs/specs/SPEC-order-history.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: 2026-11-19 사용자가 머지 뒤 Linux 실제 창에서 확인 순서 1~8과 탭 자동 새로 고침 · 스크롤 유지를 확인, 정상 (OKF `docs/okf/2026-11-19-order-history.md`)
- **확인하지 못하는 것**: 목록 · 상세 불러오기 실패와 [다시 시도](모의 서버를 화면에서 실패시킬 수 없어 테스트로만 확인), 실제 터치스크린과 화상 숫자 자판, 1024 × 768 화면
- **다른 문서에 있는 것**: 그날 픽업완료 · 제조완료 주문의 [주문취소]는 T18, [재제조] · 처리 이력의 재제조 줄은 T21, 「환불」 상태는 T22 시나리오를 본다. 인쇄 버튼은 T12 시나리오를 본다.

## 준비

| 순서 | 할 일 |
|---|---|
| P1 | 점포번호 탭에서 점포코드 `ST000001`, 비밀번호 `1234`로 로그인 (모의 계정) |
| P2 | 화면 왼쪽 아래 「개발용 모의 주문」을 펼치고 [주문 1건]을 세 번 누른다. 오늘 모의 주문은 연락처 끝 4자리가 모두 `0000`이다 |
| P3 | 지난 날 주문은 모의 서버가 한 달 치(하루 3~6건, 픽업완료 · 매장취소 · 고객취소 · 환불)를 만들어 둔다 |

## A. 기간

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A1 | 주문내역 탭을 처음 연다 | [오늘]이 골라져 있고 P2 주문 세 건이 보인다. 요약 줄 「총 3건 · 결제 합계 ₩…」 | |
| A2 | [어제] → `>` | 어제 주문 → 다시 오늘. 오늘에서는 `>`가 막혀 있다 | |
| A3 | [최근 한 달] | 한 달 전 같은 날부터 오늘까지. `<`가 막혀 있다 | |
| A4 | 기간 글자(가운데 날짜)를 누른다 | 달력이 열린다. 한 달 전 같은 날 이전 날짜는 흐리고 「이전 내역은 웨일ERP에서 볼 수 있습니다.」 | |
| A5 | 달력에서 이틀을 골라 [확인] | 그 이틀 기간으로 바뀐다. `<` `>`는 이틀씩 움직인다 | |
| A6 | 달력을 다시 열고 바깥을 누른다 | 기간은 그대로, 달력만 닫힌다 | |

## B. 상태 탭 · 목록

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B1 | [최근 한 달] → 탭 줄을 본다 | 「전체 · 접수대기 · 제조중 · 제조완료 · 픽업완료 · 취소」 뒤에 건수. 「취소」 탭에는 매장취소 · 고객취소 · 환불이 섞여 있다 | |
| B2 | 「전체」 탭의 요약 줄 | 「총 N건 · 결제 합계 ₩… (취소 M건 제외)」 | |
| B3 | [오늘] → 「접수대기」 탭 | P2 주문 행이 노란 배경, 상태 글자 주황 「접수대기」. 열은 픽업번호 · 고객 · 메뉴 · 금액 · 상태 · 주문일시, 최신이 위 | |
| B4 | [최근 한 달]에서 페이지당 건수를 「50건씩」으로 바꾸고 페이지 번호 · [다음]을 누른다 | 한 페이지에 50건, 페이지가 넘어간다 | |
| B5 | 앱을 껐다 켜고 다시 로그인 → 주문내역 | 페이지당 건수가 「50건씩」 그대로 | |

## C. 검색

## D. 상세

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| D1 | 오늘 접수대기 행을 연다 | 제목 「#번호 접수대기」. 「주문 메뉴」(메뉴 · 단가 · 수량 · 금액, 합계), 「기본 정보」(연락처 「***-****-0000」, 「첫 주문」 또는 「N번째 주문」), 「결제정보」, 「처리 이력」 「결제(주문)」 줄 | |
| D2 | 같은 상세의 아래 버튼 | [영수증 인쇄](「영수증」 프린터가 없으면 막힘) · [주문서 인쇄](막힘) · [주문취소] · [주문접수](파란색) | |
