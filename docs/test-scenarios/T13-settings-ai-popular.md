## A. 웨일ERP 계정 — 목록 · 추가

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A1 | 화면을 본다 | 안내 「AI챗봇 인기메뉴에 노출할 메뉴를 추가합니다. 최대 5개까지 설정할 수 있습니다.」, [+ 인기상품 추가], 「2 / 5개」. 목록은 상품명 · 카테고리 · 금액 · [삭제], 먼저 추가한 「아메리카노」가 위이고 「일시품절」 꼬리표가 붙어 있다 | |
| A2 | [+ 인기상품 추가] | 팝업 「인기상품 추가」. 탭에 [전체]와 카테고리만 있고 [옵션]은 없다. 「아메리카노」 · 「카페라떼」는 「등록됨」, 「치즈케이크」는 회색이라 체크가 안 된다 | |
| A3 | 「바닐라라떼」 체크 | 「1개 선택됨 (최대 2개 더)」 | |
| A4 | 「얼그레이」 · 「티라미수」까지 체크 | 「3개 선택됨 (최대 0개 더)」, 나머지 상품은 체크가 막힌다 | |
| A5 | [추가하기] | 「3개를 인기메뉴에 추가했습니다.」. 팝업은 열린 채 세 개가 「등록됨」 | |
| A6 | [닫기] | 「5 / 5개」, 목록 아래에 새 세 개. [+ 인기상품 추가]가 막혀 있다 | |

## B. 삭제 · 품절 꼬리표

| ID | 동작 | 기대 결과 | 결과 |
