# 테스트 시나리오: T11 프린터설정

- **태스크**: T11 프린터설정 (Plane WHALEERPPO-12), 개편판(2026-11-18) 포함
- **스펙**: `docs/specs/SPEC-settings-printer.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: 2026-11-17 Linux `pnpm tauri dev`에서 칸 3개와 [+ 프린터 추가] 팝업을 사용자가 확인 (`docs/okf/2026-11-17-settings-printer.md`). 2026-11-18 사무실 SEWOO SLK-TS100(USB + Windows 드라이버)에서 시험 인쇄 정상 출력 (`AGENTS.md` 현재 단계). 개편판 체크리스트 8개는 Windows 확인 대기 (`docs/okf/2026-11-18-printer-revision.md`)
- **개발 모드 동작 (T12 뒤)**: Linux는 프린터 목록이 비어 있어 개발 모드에서는 시험용 이름 「Microsoft Print to PDF」 「SLK-TS100」 「카운터 영수증 프린터」를 대신 보인다. [시험 인쇄]는 실제로 출력하지 않고 오른쪽 아래 「출력 미리보기」에 쌓으며 늘 성공으로 본다.
- **확인하지 못하는 것**: 실물 출력물(한글 · 줄바꿈 · 커팅), 시험 인쇄 실패 문구, 프린터 목록 오류(스풀러 중지), Windows 목록에서 사라진 프린터의 「(찾을 수 없음)」, 설정 파일 저장 · 읽기 실패 문구. 모두 Windows 묶음이나 테스트로만 본다. 실제 터치스크린.

## 준비

| 항목 | 내용 |
|---|---|
| 실행 | `GDK_BACKEND=x11 pnpm tauri dev` |
| 로그인 | 점포번호 계정 ST000001 / 1234 (점포번호 계정도 모든 설정을 바꿀 수 있다) |
| 화면 | 환경설정 탭 → [프린터설정] |
| 설정 파일 | Linux `~/.config/com.whale.pickuporder.dev/printer-settings.json`. 처음부터 보려면 앱을 끈 뒤 이 파일을 지운다 |

## A. 칸 · 프린터 추가

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A-1 | 설정 파일 없이 화면을 연다 | 칸 3개 「슬롯 1 — 프린터 없음」 …, 각 칸에 [+ 프린터 추가]. 칸 위에 「주문서를 출력할 프린터가 없습니다. 주문을 접수해도 주문서가 출력되지 않습니다.」. 아래 「프린터 추가 방법」 세 줄. 「마스터 계정만」 안내는 없다 | |
| A-2 | 슬롯 1의 [+ 프린터 추가] | 팝업 「프린터 선택」에 프린터 이름 3개와 [취소] | |
| A-3 | 「SLK-TS100」을 고른다 | 슬롯 1이 「슬롯 1 — SLK-TS100」. 「주문서」 체크, 「영수증 (고객 요청 시)」 해제, 「용지 폭」 80mm, 용도 빈칸. 「저장되었습니다」 토스트가 아래 가운데에 2초. 주문서 프린터 없음 안내가 사라진다 | |
| A-4 | 슬롯 2의 [+ 프린터 추가] | 「SLK-TS100」은 흐리고 누를 수 없다 | |

## B. 칸 고치기 · 저장

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B-1 | 연필(「용도 이름 고치기」)을 눌러 ` 카운터 `를 넣고 Enter | 「카운터」(앞뒤 공백 제거)로 보이고 「저장되었습니다」 | |
| B-2 | 「영수증 (고객 요청 시)」 체크, 「용지 폭」 58mm | 바꿀 때마다 「저장되었습니다」. 연달아 바꿔도 토스트가 겹치지 않는다 | |
| B-3 | 「주문서」 체크를 푼다 | 주문서 프린터 없음 안내가 다시 보인다. 다시 체크하면 사라진다 | |
| B-4 | [프로그램 종료] 뒤 다시 켜서 같은 화면 | 프린터 · 용도 · 체크 · 용지 폭이 그대로다. 설정 파일이 생겨 있다 | |
| B-5 | [시험 인쇄] | 「시험 인쇄를 보냈습니다.」. 「출력 미리보기」 수가 늘고, 열면 「시험 인쇄」 종이에 「픽업오더 주문접수 시험 인쇄」 · 「프린터: …」 · 「용도: 카운터」 · 「점포: 모의 점포 (개발용)」 · 「출력 시각: …」 · 한글 문장 줄 | |
| B-6 | [연결 해제] | 확인창 없이 「슬롯 1 — 프린터 없음」으로 돌아간다 | |
