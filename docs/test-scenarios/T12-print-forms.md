# 테스트 시나리오: T12 출력 — 주문서 · 영수증

- **태스크**: T12 출력 — 주문서 · 영수증 (Plane WHALEERPPO-13)
- **스펙**: `docs/specs/SPEC-print-forms.md` (12장 도착 예정 시각은 T19(2026-11-27)에서 반영했다: 주문서 「도착예정: HH:mm」, 영수증 · 취소 영수증은 주문번호 다음 줄에 「도착예정: HH:mm」)
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버. 개발 모드라 실제 인쇄 대신 화면 오른쪽 아래 [출력 미리보기 (N)]에 종이 모양으로 쌓이고, 출력은 늘 성공으로 본다. 프린터 목록도 시험용 이름(「Microsoft Print to PDF」 · 「SLK-TS100」 · 「카운터 영수증 프린터」)이 대신 나온다
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: 없음. Linux 실제 창은 결과를 따로 받지 않았고, Windows 실물 체크리스트는 프린터 기계 이상으로 확인하지 않고 승인했다 (OKF `docs/okf/2026-11-19-print-forms.md`)
- **확인하지 못하는 것**: 개발 모드에서는 출력이 실패하지 않으므로 빨간 띠 · 경고음 · 「미출력」 꼬리표 · [다시 인쇄] · 30초 시간 초과는 아래 E 묶음(실물 프린터에서만)으로 따로 둔다. 실물 출력물의 한글 · 줄바꿈 · 커팅 · 용지 폭. 실제 터치스크린
- **다른 문서에 있는 것**: 재제조 주문서는 T21, 취소 영수증(금액 마이너스)은 T22 B-4 시나리오를 본다

## 준비

| 순서 | 할 일 |
|---|---|
| P1 | 점포번호 탭에서 점포코드 `ST000001`, 비밀번호 `1234`로 로그인 (모의 계정) |
| P2 | 환경설정 탭 → [프린터설정] → [+ 프린터 추가] → 「프린터 선택」에서 「SLK-TS100」. 슬롯 1의 「주문서」가 체크돼 있고 용지 폭 80mm인지 본다 (바꾸면 바로 「저장되었습니다」) |
| P3 | [+ 프린터 추가] → 「카운터 영수증 프린터」. 슬롯 2는 「주문서」를 풀고 「영수증 (고객 요청 시)」를 체크 |
| P4 | 오른쪽 아래 [출력 미리보기 (N)]를 열어 [비우기] |
| P5 | 왼쪽 아래 「개발용 모의 주문」을 펼친다. 세 번째마다 메뉴 5줄 · 옵션 · 요청사항이 있는 긴 주문이 온다 |

## A. 시험 인쇄

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A1 | 슬롯 1 [시험 인쇄] | 「시험 인쇄를 보냈습니다.」, 미리보기에 「SLK-TS100 · 80mm · 시험 인쇄」 한 장 | |

## B. 주문서 자동 출력

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B1 | [주문 1건] → 주문접수 화면 카드의 [주문접수] | 미리보기에 「SLK-TS100 · 80mm」 한 장만(슬롯 2는 안 나옴). 제목 「픽업오더 주문서 (주방 / 바리스타용)」, 가장 큰 「#번호」, 주문번호 · 주문일시 · 주문자 「홍*동 (0000)」 · 「도착예정: HH:mm」(T19), 메뉴 「아이스 아메리카노(시험) × 1」. 요청사항 줄은 없다 | |
| B2 | 긴 주문이 올 때까지 [주문 1건] → 그 주문을 [주문접수] | 「요청사항: …」이 굵게, 옵션은 「ㄴ 샷 추가」처럼 한 줄에 하나, 메뉴 사이 구분선, 긴 줄은 80mm 폭에서 줄바꿈 | |
| B3 | [주문 1건] → 바탕화면 위젯 카드의 [주문접수] | 본 창에서 접수한 것과 같이 한 장 | |
| B4 | [주문 1건] → 카드를 눌러 요약 팝업 → [주문접수] | 한 장. 같은 주문이 두 번 나오지 않는다 | |
| B5 | [주문 1건] → [다른 PC가 접수] | 미리보기 장 수가 늘지 않는다 | |
| B6 | 슬롯 1 용지 폭을 58mm로 → [주문 1건] → [주문접수] | 「58mm」 표시, 80mm보다 좁게 줄바꿈된다. 확인 뒤 80mm로 되돌린다 | |

## C. [주문서 인쇄]

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| C1 | 접수대기 카드의 요약 팝업 | [주문서 인쇄]가 막혀 있다 | |
| C2 | B1 주문(제조중)의 요약 팝업 → [주문서 인쇄] | 맨 위 「[재출력] HH:mm」(누른 시각)이 붙은 주문서 한 장 | |
| C3 | 주문내역 탭에서 같은 주문 상세 → [주문서 인쇄] | C2와 같다 | |
| C4 | [프린터설정]에서 슬롯 1의 「주문서」를 푼다 | 빨간 안내 「주문서를 출력할 프린터가 없습니다. 주문을 접수해도 주문서가 출력되지 않습니다.」 | |
| C5 | [주문 1건] → [주문접수], 그다음 그 주문 요약 팝업 → [주문서 인쇄] | 접수 때는 아무것도 나오지 않는다. [주문서 인쇄]는 토스트 「주문서를 출력할 프린터가 없습니다.」. 확인 뒤 「주문서」를 다시 체크 | |

## D. [영수증 인쇄]

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| D1 | 접수대기 카드 요약 팝업 → [영수증 인쇄] | 접수대기에서도 눌린다. 「영수증 미리보기」 팝업에 영수증 모양 + [영수증 인쇄] [닫기] | |
| D2 | 미리보기 팝업의 [영수증 인쇄] | 토스트 「영수증을 출력했습니다.」, 팝업이 닫히고 출력 미리보기에 「카운터 영수증 프린터」로 한 장 | |
| D3 | 주문내역 → [최근 한 달]에서 결제수단이 「신용카드」 · 「카카오페이」 · 「포인트 결제」인 주문을 하나씩 열어 [영수증 인쇄] | 카드: 카드번호 · 거래종류 · 거래구분 · 승인번호 · 승인일시 · 매입사명. 카카오페이: 결제수단 · 승인번호 · 승인일시만. 포인트 결제: 결제 줄 대신 「결제 금액 0원」과 할인 내역 | |
| D4 | [프린터설정]에서 슬롯 2의 「영수증 (고객 요청 시)」를 푼다 → 요약 팝업 · 주문내역 상세 | [영수증 인쇄]가 막혀 있다 | |

## E. 실물 프린터에서만 (Windows 설치 파일 + 사무실 프린터 SEWOO SLK-TS100)

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| E1 | 슬롯 1 SLK-TS100 「주문서」 80mm, [시험 인쇄] | 한글이 깨지지 않고 나온다 | |
| E2 | 주문 접수 → 자동 출력 | 한 장. 픽업번호 큰 글씨가 잘리지 않고, 구분선 · 요청사항 굵게가 보인다. 커팅 위치가 맞다 | |
| E3 | 긴 주문 · 58mm 설정 | 줄바꿈 · 다음 장 이어짐, 오른쪽이 잘리지 않는다 | |
| E4 | 「주문서」 프린터 두 대 중 한 대의 케이블을 뽑고 접수 | 접수는 그대로. 경고음 한 번, 화면 아래 빨간 띠 「주문서를 출력하지 못했습니다. (슬롯 N 프린터이름: 이유) [다시 인쇄] [×]」, 주문 카드 · 위젯 카드에 「미출력」 | |
| E5 | 케이블을 다시 꽂고 띠의 [다시 인쇄] | 실패한 쪽만 한 장, 띠와 「미출력」이 사라진다 | |
| E6 | 실패 띠가 있는 주문을 [주문취소] | 띠와 「미출력」이 같이 사라진다 | |
| E7 | 인쇄 스풀러 서비스를 멈추고 접수 | 30초 뒤 「출력 결과를 확인할 수 없습니다. (…)」 띠 · 「미출력」 · 경고음. 스풀러를 다시 켠 뒤 늦은 결과가 화면을 바꾸지 않는다 | |
| E8 | [영수증 인쇄] 실물 출력 | 왼쪽 메뉴 · 오른쪽 금액 정렬 | |
