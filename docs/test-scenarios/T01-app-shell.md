# 테스트 시나리오: T01 프로그램 틀

- **태스크**: T01 프로그램 틀 (Plane WHALEERPPO-2), 개편판(2026-11-18) 포함
- **스펙**: `docs/specs/SPEC-app-shell.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: 2026-11-16 작업 세션이 Linux에서 창이 오류 없이 뜨는 것까지 확인. 창 동작 체크리스트(처음 14개, 개편판 9개)는 Windows 확인 대기였다 (`docs/okf/2026-11-16-app-shell.md`, `docs/okf/2026-11-18-app-shell-revision.md`)
- **확인하지 못하는 것**: 실제 터치스크린. 1024 × 768 모니터 · 배율 125~150% 화면. 모니터 2대. 한글 앱 이름의 실행 파일 · 바로가기. 켤 때 1280 × 800이 잠깐 보이는 것은 알려진 현상이라 실패로 보지 않는다.

## 준비

| 순서 | 할 일 |
|---|---|
| P1 | `GDK_BACKEND=x11 pnpm tauri dev`로 켠다 (KDE Wayland에서는 창 위치가 무시된다) |
| P2 | 로그인이 필요한 묶음은 점포번호 탭에서 점포코드 `ST000001`, 비밀번호 `1234`로 로그인한다 (모의 계정) |
| P3 | C 묶음은 화면 왼쪽 아래 「개발용 모의 주문」을 펼친다 |

## A. 화면 틀 · 창

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A-1 | 로그인하지 않은 채 창을 본다 | 제목 표시줄 없는 창. 헤더에 「픽업오더 주문접수」와 「로그인 후 이용해주세요.」. [주문 받기] 토글은 없다 | |
| A-2 | 로그인한다 | 헤더에 점포명 「모의 점포 (개발용)」과 [주문 받기] 토글(OFF). 탭 「주문접수」 「주문내역」 「매장정보」 「메뉴품절」 「환경설정」 | |
| A-3 | 「환경설정」 탭을 누른다 | 하위 탭 「위젯설정」 「프린터설정」 「AI챗봇 인기메뉴 설정」 | |
| A-4 | 헤더 빈 곳(로고 · 점포명 포함)을 끈다 | 창이 따라 움직인다. 토글 · [더보기] 버튼 위에서 끌면 창이 움직이지 않는다 | |
| A-5 | 헤더 빈 곳을 두 번 누른다 | 창 늘리기 ↔ 줄이기가 바뀐다 | |
| A-6 | [더보기]를 연다 (로그인 뒤) | 아이콘 칸: [새로고침] [다시시작] [로그아웃] [프로그램 종료](빨간 아이콘) [창 최소화] [창 늘리기] 또는 [창 줄이기](하나만) [로그 확인] | |
| A-7 | 로그아웃한 상태에서 [더보기]를 연다 | [새로고침] · [로그아웃]이 없다 | |
| A-8 | 메뉴를 연 채 헤더 빈 곳이나 화면 내용을 누른다 | 메뉴가 닫힌다 | |
| A-9 | [창 최소화] → 작업표시줄에서 다시 연다 | 내려갔다가 돌아온다 | |
| A-10 | 늘린 상태에서 [창 줄이기] | 1280 × 800으로 줄고 화면 가운데로 간다 (작업 영역이 더 작으면 작업 영역 크기) | |
| A-11 | 창 테두리를 끌어 줄인다 | 1024 × 768보다 작아지지 않는다 | |
| A-12 | 창을 줄여 옮긴 뒤 [프로그램 종료]로 끄고 다시 켠다 | 같은 크기 · 위치로 열린다. 늘린 상태로 끄면 늘린 상태로 열린다 | |

## B. 주문받기 토글

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B-1 | 토글을 누른다 (OFF → ON) | 확인창 없이 잠깐 잠긴 뒤 「ON」(초록) | |
| B-2 | 다시 누른다 (ON → OFF) | 확인창 「주문수신을 중단하시겠습니까?」, 문구 「주문 수신이 중단되면 고객은 앱에서 주문을 할 수 없습니다.」, [주문 중단] | |
| B-3 | [취소] / 다시 열어 [주문 중단] | 취소면 ON 그대로, [주문 중단]이면 「OFF」 | |
| B-4 | 개발 패널 [연결 끊기] → 토글 ON을 누른다 → [연결 잇기] | 토스트 「처리하지 못했습니다. 잠시 뒤 다시 시도해 주세요.」, 토글은 OFF 그대로 | |

## C. 확인창 · 종료

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| C-1 | [더보기] → [로그아웃] → [로그아웃] | 확인창 「로그아웃 하시겠습니까?」 「주문 수신이 자동으로 중단됩니다.」 뒤 로그인 화면 | |
| C-2 | [주문 1건] 뒤 [더보기] → [프로그램 종료] | 확인창 「프로그램을 종료하시겠습니까?」에 「처리할 주문이 1건 있습니다. 프로그램을 끄면 이 주문을 처리하거나 고객에게 알림을 보낼 수 없습니다.」. [취소]면 그대로 | |
| C-3 | 같은 상태에서 토글 OFF · [다시시작] 확인창을 연다 | 각각 「처리할 주문이 1건 있습니다. 주문받기를 꺼도 이 주문은 처리해야 합니다.」 / 「… 다시 켜도 이 주문은 그대로 처리할 수 있습니다.」 | |
