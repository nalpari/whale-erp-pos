# 테스트 시나리오: T06 바탕화면 위젯 · 알림음

- **태스크**: T06 바탕화면 위젯 · 알림음 (Plane WHALEERPPO-7)
- **스펙**: `docs/specs/SPEC-desktop-widget.md`
- **환경**: Linux 개발 PC, `GDK_BACKEND=x11 pnpm tauri dev`, 모의 서버. KDE Wayland에서 그냥 켜면 위젯 위치 · 항상 위가 무시되므로 반드시 `GDK_BACKEND=x11`로 켠다.
- **처음 작성**: 2026-11-26 (지난 태스크 소급 작성, main 코드 기준)
- **이전 확인**: `GDK_BACKEND=x11`로 다시 켜서 확인 순서 1~8대로 확인, 정상 (2026-11-19, OKF 「검증」. 소리 크기는 T10에서 조절하기로 함)
- **확인하지 못하는 것**: 소리가 충분히 크고 「딩동」과 경고음이 구분되는지(사람이 귀로 판단), 기존 POS가 앞일 때 위젯이 위에 뜨고 POS 입력 초점을 빼앗지 않는지, 화면을 한 번도 안 누른 채 첫 소리, 10분 넘게 최소화한 동안 30초 반복, 화면 배율 125 · 150%(모두 Windows 체크리스트), 위젯 ↔ 본 창 연결 실패 안내 「본 화면에서 처리해 주세요」(일부러 만들 방법이 없어 테스트로만 확인)

## 준비

| 순서 | 할 일 |
|---|---|
| P1 | 「점포번호로 로그인」 탭에서 점포코드 `ST000001`, 비밀번호 `1234`로 로그인 (모의 계정) |
| P2 | 화면을 한 번 눌러 둔다 (소리 장치를 깨운다) |
| P3 | 화면 왼쪽 아래 「개발용 모의 주문」을 펼친다. 환경설정 탭 → [위젯설정]은 기본값(접수대기 · 제조중 · 제조완료 표시, 우하단) |

## A. 알림음

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| A1 | 본 창을 앞에 둔 채 [주문 1건] | 「딩동」 한 번. 위젯은 뜨지 않는다 | |
| A2 | 접수하지 않고 30초 기다린다 | 30초마다 「딩동」이 다시 난다 | |
| A3 | [5초 뒤 주문 3건(같은 순간)] | 3건이 들어와도 소리는 한 번 | |
| A4 | 접수대기를 모두 [주문접수] | 30초 반복이 멈춘다 | |

## B. 위젯 뜨기 · 모양

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| B1 | [5초 뒤 주문 1건] → 5초 안에 더보기 [창 최소화] | 주 모니터 오른쪽 아래(여백 16px)에 「새 주문 알림」 위젯 + 소리. 위젯이 작업표시줄에 따로 안 보인다 | |
| B2 | 다른 창을 눌러 본다 | 위젯이 계속 맨 위에 있고 다른 창 입력이 막히지 않는다 | |
| B3 | 위젯 카드를 본다 | 상태 · 주문시간, 픽업 예정, 픽업번호, 요청사항 1줄, 메뉴 2줄 + 「+ 외 N개」. 접수대기가 먼저, 오래된 것이 위 | |
| B4 | 최소화한 채 [주문 10건] | 카드는 최대 5장, 아래 「+ N건 더 있음」 | |

## C. 위젯에서 처리

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| C1 | 위젯 접수대기 카드 [주문접수] → [제조완료] | 위젯 카드와 본 창 카드가 함께 바뀐다 | |
| C2 | [픽업완료] | 위젯 카드 안에 [완료 취소(05)]가 5초 보이고, 누르면 제조완료로 돌아온다 | |
| C3 | 접수대기 카드 [주문취소] | 본 창이 앞으로 오고 취소 사유 팝업이 열린다 | |
| C4 | 위젯 카드의 버튼 밖을 누른다 | 본 창이 앞으로 와서 「주문접수」 탭 첫 탭 + 그 주문 요약 팝업. 팝업을 닫으면 그 카드로 스크롤된다 | |
| C5 | 「+ N건 더 있음」을 누른다 | 본 창 「주문접수」 탭 첫 탭 | |

## D. 닫기 · 다시 뜨기 · 자동 OFF

| ID | 동작 | 기대 결과 | 결과 |
|---|---|---|---|
| D1 | 본 창을 최소화한 채 접수대기 카드의 [×](이 주문 닫기) | 그 카드만 사라지고, 30초 뒤 소리와 함께 다시 뜬다 | |
| D2 | 머리 [×](위젯 닫기) | 위젯 전체가 접힌다. 접수대기가 남아 있으면 30초 뒤 또는 다음 새 주문 때 다시 뜬다 | |
| D3 | 본 창을 최소화한 채 「주문 받기」 ON에서 [미접수 2건 자동 OFF] | 위젯 맨 위에 빨간 안내 카드 「접수하지 않은 주문 2건이 자동 취소되어 주문받기가 꺼졌습니다. …」 | |
| D4 | 더보기 [프로그램 종료] → [프로그램 종료] | 본 창과 함께 위젯도 닫힌다 | |
