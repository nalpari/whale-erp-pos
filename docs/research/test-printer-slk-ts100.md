## 사무실에 꽂혀 있던 선

프린터 쪽은 작은 랜선 모양, PC 쪽은 9핀 암컷이다. 프린터의 그 단자에는 **"RS-232"** 라고 적혀 있다 (2026-11-17 담당자 확인). 매뉴얼의 3번 구성(RJ45 모양의 시리얼 단자)에 해당하므로, 이 선은 **시리얼(RS-232) 선**이다. PC의 COM 포트(9핀 수컷)나 USB-시리얼 변환기에 꽂는다.

## 우리 개발과의 관계

- 화면정의서가 전제한 방식(Windows에 설치한 프린터를 목록에서 고르기, p.19)과 포트 직접 출력 방식을 **이 기기 하나로 둘 다 시험할 수 있다** (`AGENTS.md` 미결정 표 "프린터 모델 · 연결 방식").
- 용지 없음 · 덮개 열림 센서가 있으므로, 포트 직접 방식이면 ESC/POS 상태 요청으로 읽을 수 있을 가능성이 있다 (기획자 문의 Q47). 매뉴얼에 상태 명령 설명은 없어 확인이 필요하다.
- 사무실 테스트는 USB 연결 + Windows 드라이버가 가장 간단하다.

## 확인한 것 (2026-11-18)

- USB 연결 + Windows 드라이버로 설치한 뒤, 매장 프로그램 [프린터설정]의 [시험 인쇄](Windows 드라이버 출력, T11)로 한글이 들어간 시험 페이지가 정상 출력됐다 (담당자 확인). 그래서 아래 1번(한글 출력)은 드라이버 방식에서는 확인됐다. 포트 직접 출력에서의 한글은 아직 모른다.

## 확인하지 못한 것

1. **한글 출력**: 한글 매뉴얼에도 한글 글꼴 · 코드 페이지 설명이 없다. 셀프 테스트 출력이나 실제 출력으로 확인해야 한다.
2. **상태를 PC가 받는 방법**: 센서는 있지만, 어떤 명령으로 어떤 값을 돌려주는지와 Windows 드라이버 방식에서 상태를 알 수 있는지는 매뉴얼에 없다.
3. **커터 종류**: 매뉴얼(Guillotine)과 데이터시트(Partial)가 다르다. 실제 출력으로 완전 절단인지 부분 절단인지 본다.
4. 드라이버 파일 내려받는 위치 (miniprinter.com 안의 정확한 페이지).

## 확인 방법 메모

- 셀프 테스트 (매뉴얼 9쪽): 전원 코드를 꽂고 전원이 꺼진 상태에서 FEED 버튼을 누른 채 전원 버튼을 누르고, 인쇄가 시작되면 뗀다. 펌웨어 버전, 상태, 구성이 인쇄된 뒤 Config Mode(시리얼 속도, 인쇄 농도, 멜로디 설정)로 들어간다.
