# 구현 계획: 프로그램 틀 · 헤더 · 창 제어 (`app-shell`, T01)

- **스펙**: `docs/specs/SPEC-app-shell.md` (2026-11-16 승인)
- **Plane**: WHALEERPPO-2. Plane에는 태스크(T01) 하나만 두고, 아래 단계는 이 문서의 체크리스트로 관리한다.
- **선행**: T00 프로젝트 골격이 `main`에 들어온 뒤 시작한다. 파일 경로는 T00 결과를 보고 작업 세션이 맞춘다.
- **상태**: 승인 (2026-11-16, 사용자)

## 개요

로그인 전/후 화면 틀, 헤더와 탭, 주문받기 토글, 더보기 메뉴(창 제어 · 로그아웃 · 시스템종료)를 만든다. 로그인 상태는 T02가 만들기 전까지 모의 상태로 바꿔 본다.

## 구조 결정

- 화면 코드는 Tauri를 직접 부르지 않고 `src/shared/platform/window.ts`를 거친다. 테스트 · 브라우저 개발 모드에서는 가짜 구현을 쓴다 (스펙 3장).
- 서버 요청은 `StoreStatusApi` 인터페이스 뒤의 모의 구현으로 한다 (스펙 3장).
- 상태는 React Context + useReducer (스펙 11장 D). 라우터 없이 화면 상태로 탭을 바꾼다.
- 확인 팝업은 공용 컴포넌트 하나로 만들어 토글 OFF · 로그아웃 · 시스템종료가 같이 쓴다.

## 단계

### 1단계. 화면 틀과 탭 전환

로그인 전/후에 헤더 · 탭 · 콘텐츠 영역이 바뀌고, 탭 5개와 환경설정 하위 탭 3개를 오갈 수 있다. 로그인 상태는 모의 값(개발용 전환 수단)으로 바꾼다.

- 완료 기준
  - [ ] 로그인 전: "로그인 후 이용해주세요.", 탭 · 토글 숨김 (스펙 9장 1)
  - [ ] 로그인 후: 점포명, 탭 5개, 첫 탭은 주문접수 (스펙 9장 1)
  - [ ] 탭 5개 · 환경설정 하위 탭 3개 전환 (스펙 9장 4)
- 검증: 화면 테스트, `pnpm dev`로 화면 확인
- 파일(예상): `src/app/`, `src/features/app-shell/` (헤더, 탭), 테스트
- 크기: M

### 2단계. 창 제어와 제목 표시줄 없는 창 (위험이 커서 앞에 둔다)

Tauri 창 감싸기 모듈을 만들고, 제목 표시줄을 없앤 창에서 헤더를 끌어 옮기고, 최소화 · 줄이기(1280×800, 가운데) · 늘리기가 동작하게 한다. Alt+F4 같은 운영체제 닫기를 가로챌 수 있는지 확인한다.

- 완료 기준
  - [ ] `window.ts` 감싸기 + 가짜 구현, 화면 코드는 이것만 부름 (테스트)
  - [ ] 제목 표시줄 없음, 헤더 끌기로 창 이동, 헤더 안 버튼은 끌기에서 제외
  - [ ] 최소화 · 줄이기 · 늘리기 버튼이 감싸기 함수를 부름 (테스트). 실제 동작은 Windows 확인
  - [ ] Alt+F4 가로채기 가능 여부와 방법을 Tauri v2 공식 문서로 확인해 보고 (안 되면 보고만)
  - [ ] 필요한 Tauri 창 권한만 열기
- 검증: 화면 테스트, 가능하면 `pnpm tauri dev`, Windows 확인 체크리스트 작성
- 파일(예상): `src/shared/platform/window.ts`, `src-tauri/tauri.conf.json`, `src-tauri/capabilities/*`, 헤더 컴포넌트, 테스트
- 크기: M

### 3단계. 확인 팝업과 주문받기 토글

공용 확인 팝업을 만들고, 토글을 `StoreStatusApi` 모의 구현에 연결한다.

- 완료 기준
  - [ ] 로그인 직후 OFF. ON은 확인 없이, OFF는 팝업 뒤에 요청 (스펙 2.2)
  - [ ] 요청 중 다시 누를 수 없음, 실패하면 원래 상태 + "서버에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요." (스펙 2.2)
  - [ ] 팝업 문구가 화면정의서 원문과 같음, [취소]면 아무것도 안 바뀜 (테스트)
- 검증: 단위 · 화면 테스트
- 파일(예상): `src/shared/ui/confirm-dialog`, `src/shared/api/store-status.ts`, `src/features/app-shell/` 토글, 테스트
- 크기: M

### 4단계. 더보기 메뉴: 로그아웃 · 시스템종료

- 완료 기준
  - [ ] 로그아웃: 팝업 → 주문 중단 요청 → 로그인 화면. 요청이 실패해도 진행 (스펙 2.3)
  - [ ] 시스템종료: 팝업 → 주문 중단 요청 → 로그아웃 → 프로그램 종료. 로그인 전에도 팝업 (스펙 2.3)
  - [ ] Alt+F4를 가로챌 수 있으면 시스템종료와 같은 팝업 (2단계 확인 결과에 따라)
  - [ ] 로그인 전에는 로그아웃 버튼 숨김
- 검증: 화면 테스트 (종료는 감싸기 함수 호출로 확인)
- 파일(예상): `src/features/app-shell/` 더보기 메뉴, 테스트
- 크기: S~M
